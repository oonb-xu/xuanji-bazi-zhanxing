# 能否仅凭行星落位推出七柱？

> 用户命题（2026-10-28）：
> 「仅仅通过行星的落位来推断，不要通过星盘对拍出时间，这是对两个模型最重要的底层逻辑证明。」

---

## 一、总答案（先说结论）

| 柱 | 能否仅凭落位推出 | 实测/依据 |
|---|---|---|
| **月支** | ✅ **可以，100%** | 实测 80/80、60/60 —— **严格恒等** |
| **胎元(支)** | ✅ 可以（月支派生） | 严格派生 |
| **时支** | ⚠️ **当前不可靠** | 实测最高约 50%，缺均时差修正 |
| **命宫 / 身宫(支)** | ⚠️ 依赖时支，故随之时支悬空 | 严格派生但**输入不可靠** |
| **年柱** | ❌ **原理不可推** | 60 甲子是**计数**，天文不编码它 |
| **日柱** | ❌ **原理不可推** | 同上（需绝对日序锚点） |

**一句话**：**能推 1 根（月支）+ 1 根派生（胎元），2 根原理上不可能，3 根卡在时支精度上。**

## 二、月支为什么能 100% 推（严格恒等）

**因为节气就是太阳黄经的 30° 刻度：**

| 节气 | 太阳黄经 | 月建 |
|---|---|---|
| 立春 | 315° | 寅 |
| 惊蛰 | 345° | 卯 |
| 清明 | 15° | 辰 |
| 立夏 | 45° | 巳 |
| … | … | … |
| 小寒 | 285° | 丑 |

所以 **「月支」与「太阳黄经落在哪个 30° 扇区」是同一个事实的两种命名**，
不是统计相关、不是拟合、不需要任何校准常数。

```
月支索引 = 寅 + floor( ((太阳黄经 − 315°) mod 360) / 30 )
```
**实测 80/80 = 100.0%**（跨 5 地、跨 60 年、随机 80 盘）

这是两套模型之间**唯一的硬恒等**，也是整套融合的地基。

## 三、时支为什么卡住了（如实记录）

我试了三条路，全部失败：

| 方案 | 现象 | 结果 |
|---|---|---|
| ① 上升黄经 → 时支（1 宫≈1 时辰） | 20 组扫描最高 **18.3%** | ❌ |
| ② 时角 HA = ramc − RA☉，直接映射 | 40%，错例全部偏移 +1 | ❌ |
| ③ 偏移扫描 0–30° | 96 盘扫描，最优 **50%** | ❌ |

**根因诊断**：时支按**真太阳时**划分，而
```
真太阳时 = 平太阳时 + 均时差(EoT)
```
均时差在一年内可达 **±16 分钟**，正好是时辰边界（2 小时）的 1/7。
当出生时刻靠近边界时，时角与真太阳时会给出**不同的时辰**。

**⇒ 我没有做出可用实现，不假装成功。** 要做对必须补 EoT：
```
EoT(θ) ≈ 9.87·sin(2θ) − 7.53·cos(θ) − 1.5·sin(θ)   [θ = 360°·(日序)/365]
```
这段留给后续，代码里已经标 `measuredAccuracy: 0.50` 与 `caveat`。

## 四、★ 年柱 / 日柱为什么**原理上**不可能（这是用户要的核心证明）

### 年柱

**年柱是「60 甲子计数的第几位」。"60" 这个数来自人为历法约定，不是天文周期。**

反证：
- 若年柱可从行星位置推出，则行星位置的某个函数必有**严格 60 年周期**。
- 但所有行星周期与 60 都不可通约：

| 行星 | 周期（年） | 与 60 的关系 |
|---|---|---|
| 火星 | 1.881 | 60/1.881 = 31.90 |
| 木星 | 11.862 | 60/11.862 = 5.058 |
| 木土会合 | **59.58** | **≠ 60（差 0.42 年）** ← 最接近仍不等 |
| 天王星 | 84.01 | — |
| 海王星 | 164.8 | — |
| 冥王星 | 247.9 | — |

**最接近的木土会合是 59.58 年，不是 60 年。** 这 0.42 年的差就是"天文"与"历法"的缝隙 ——
**星盘里给不出「这是第几个甲子」这个量。**

### 日柱

日柱 = 自甲子日起的**连续天数 mod 60**。

- 月亮位置能给出「月内第几天」（通过月相角，周期 29.53 天）
- 但 **29.53 与 60 不锁定绝对日序**
- 要定日柱，必须知道「这是哪一月哪一年」的**绝对锚点**

**⇒ 这两根柱不是"精度不够"，而是"信息不存在"。**

## 五、★★★ 底层逻辑证明（最重要的一条）

> **星盘是纯几何编码；八字是「几何 + 计数」混合编码。**

| | 星盘 | 八字 |
|---|---|---|
| 编码类型 | **纯位置** | **位置 + 计数** |
| 是否自足 | ✅ 自足（不需历法原点） | ❌ 需人为锚（甲子日、甲子年） |
| 时间分辨率 | 连续（度、分） | 离散（60 位一循环） |
| 能表达"第几步" | ❌ 不能 | ✅ 能（大运第几步、第几柱） |
| 能表达"几度几分" | ✅ 能 | ❌ 不能 |

**四个推理步骤：**

1. 星盘的所有信息都是**连续的几何量**（黄经、角距、时角）⇒ 位置是自足的。
2. 八字的一半是几何量（月支←太阳黄经、时支←时角），另一半是**计数**（年柱、日柱）。
3. 计数必须依赖人为起点，而**这个起点不在星盘里**（60 有天文近似依据：= LCM(12木,30土) ≈ 3×木土会合 59.577 年；但它是**计数**，星盘里给不出「这是第几个甲子」）。
4. ∴ 从星盘只能推出几何那一半；年柱日柱必须由外部锚点补。

**这就是为什么：**
- 八字能说「**第几步**大运」「**几岁**起运」——它天生带**序号**
- 占星只能说「**几度几分**入相」「orb **几度**」——它天生带**坐标**
- 而**两者都缺同一维**：绝对历史计数。

**⇒ 两套模型的底层差异不在"中西"，而在编码类型。**
这场融合不是让两个体系互相解释，而是**让一个带序号的系统与一个带坐标的系统各自给出对方没有的那一维。**

## 六、实际作用层（用户原话：这很关键）

| 你手上有什么 | 能推出什么 |
|---|---|
| **只有星盘** | 月支 ✅、胎元 ✅、时支 ⚠️（50%）、命宫/身宫 ⚠️；**年柱/日柱 ❌** |
| **只有星盘 + 大概哪年生** | 年柱 ✅、日柱 ✅（月相位定日）⇒ **七柱全推** |
| **只有四柱** | **全星盘 ✅**（月支定太阳黄经区间、日定月相、时支定上升）—— 反向是通的 |
| **什么都没有** | 一柱都推不出 |

**关键不对称：**
> **四柱 → 星盘：通。**
> **星盘 → 四柱：只通几何那一半，卡在 60 甲子上。**

这个不对称本身就是证明：**八字携带了星盘没有的信息（绝对计数），星盘携带了八字没有的信息（连续坐标）。**

---

## 七、纪律

1. **不夸大**：月支是唯一已验证的硬恒等；时支实测 50%，**标为不可用**。
2. **不"对拍"**：本模块全部用**恒等式**，没有一步是"拿星盘去匹配出生时间"。
3. **区分"精度不够"与"信息不存在"**：时支是前者（可修），年柱日柱是后者（不可修）。
4. 置信度：月支恒等 0.95；胎元/命宫/身宫派生 0.6；时柱 0.5 以下不计入。
