## Step 1 月将（映射表，直接查表）

`雨水→亥(登明) 春分→戌(河魁) 谷雨→酉(从魁) 小满→申(传送) 夏至→未(小吉) 大暑→午(胜光)
处暑→巳(太乙) 秋分→辰(天罡) 霜降→卯(太冲) 小雪→寅(功曹) 冬至→丑(大吉) 大寒→子(神后)`

- 触发点是**十二中气**（不是节）。
- 几何含义：月将 = 太阳所躔之次（见 `01-统一模型-底层规则.md` §2）。

## Step 2 天乙贵人（条件等式）

```
IF 日干 ∈ {甲,戊,庚} THEN 贵人 = (丑, 未)
IF 日干 ∈ {乙,己}   THEN 贵人 = (子, 申)
IF 日干 ∈ {丙,丁}   THEN 贵人 = (亥, 酉)
IF 日干 ∈ {壬,癸}   THEN 贵人 = (巳, 卯)
IF 日干 ∈ {辛}      THEN 贵人 = (午, 寅)
（第一个 = 昼贵，第二个 = 夜贵）
```

## Step 3 天地盘与四课

1. 地盘 = 十二支固定（子0 … 亥11，顺时针）。
2. 天盘 = 月将加于占时之上，顺时针排布 ⇒ `天盘[地] = 地 + (占时 − 月将)`。
3. 四课：
   - 一：日干寄宫 → 其上神
   - 二：一之上神 → 其上神
   - 三：日支 → 其上神
   - 四：三之上神 → 其上神

## Step 4 三传（严格优先级）

1. **贼克**：先「下克上」，统计数量。`=1` 取该上神；`>1` 取与日干同阴阳者。
   若无「下克上」，再取「上克下」，同逻辑。
2. **比用**：贼克多个且阴阳相同 → 取与日干五行/阴阳相同者。
3. **涉害**：阴阳均同 → 取受克最深者。
4. **遥克**：无贼克 → 取「克日干」或「日干克」之神为初传。
5. **昴星**：无遥克 → 阳日取地盘酉上神，阴日取天盘酉下神。
6. **特殊**：伏吟 / 返吟 / 别责 / 八专 → 只输出基础逻辑并标记。

```
顺序：贵人 螣蛇 朱雀 六合 勾陈 青龙 天空 白虎 太常 玄武 太阴 天后
```
