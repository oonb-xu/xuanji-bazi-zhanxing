## 决策一：置换检验 —— 已执行（1000 次重采样）

### 零模型（R-C4）

**打乱「行星 ↔ 黄经（宫位）」的对应**，保持每张盘的**相位结构**与**所占宫位集合**不变。
范围按 **R-V6**：只算 **对冲/四分相 × 十大行星**（轴点/交点不计入）。

### 结果

| 项 | 值 |
|---|---|
| 样本盘数 | **500**（解析失败 0） |
| 刑/冲边数 | **1,969** |
| 置换次数 | **1,000** |
| 耗时 | 0.2s |
| **观测克比例** | **37.887%** |
| 零分布均值 | 33.737% |
| 零分布标准差 | 0.8633% |
| **置换 P 值（单侧）** | **0.0010** |
| 偏离 z | **4.81** |
| 零分布 95% 区间 | 32.10% – 35.40% |

**按你的执行标准：P = 0.0010 < 0.05 → 判定「存在结构张力」。**

### 🔴 但我在下结论前做了分层核对，结果推翻了它

**分层（按相位类型 + 实际宫位差）**：

| 分层 | 观测克率 | **几何决定值** |
|---|---|---|
| 四分相 · 宫位差 3 | **21.1%**（249/1182） | **16.7%** |
| 四分相 · 宫位差 2 | 36.5%（27/74） | — |
| 四分相 · 宫位差 4 | 44.6%（33/74） | — |
| 对冲 · 宫位差 6 | **70.7%**（386/546） | **66.7%** |
| 对冲 · 宫位差 5 | 63.6%（42/66） | — |

**主层（占样本 88%）的观测值本就贴近几何决定值。**

**⇒ 置换零模型是错的零模型**：它把「对冲意味着宫位差 6」这一**结构**打乱了，
于是"真实数据比打乱数据更常相克"**成为同义反复** ——
**"对冲 ⇒ 差 6 宫 ⇒ 66.7% 相克"是映射表的算术，不是命理信息。**

**最终判定（修正自己）：降级为「几何验证器」，不作为命理信号源** ——
即你指令中 P>0.05 分支的处置，只是理由是"**P 值本身问错了问题**"而非"P 值不显著"。

### 唯一剩下的残余（下一步的正确检验）

两个主层都**略高于**几何值：四分相差3 **+4.4pp**、对冲差6 **+4.0pp**。
这个残余**可能**是真信号，也可能是换柱边界（orb 落在宫界附近）的效应。

**正确检验**：**分层内置换** —— 在每个分层内保持宫位差分布不变，只打乱"哪颗星配哪颗星"。
**本轮的零模型不是这个，所以残余未定。**

## 决策二：《现代实战成对数据采集模板》

### 已产出

| 文件 | 用途 |
|---|---|
| `data/samples/paired-template.schema.json` | **JSON Schema（Draft 2020-12）** |
| `data/samples/paired-example.json` | 格式示例（已通过校验） |
| `src/cross/paired.mjs` | `validatePaired()` 严格校验 + `alignSample()` 结构量对齐 + `loadPaired()` |
| `data/samples/paired/` | 实际样本投放目录（首期目标 30 条） |

### 三大要素（Schema 强制 required）

| 要素 | 字段 | 关键约束 |
|---|---|---|
| **1 精确出生坐标** | `birth{date,time,timePrecision,place,lon,lat,tzOffsetHours,tzName,rodden,source}` | 时刻精度枚举 `minute/hour/unknown`；**unknown 时不得参与需时柱的推演**；Rodden 评级 A 以下必须标注 |
| **2 占问时刻与事项** | `divination{date,time,tzOffsetHours,place,lon,lat,category,question,method}` | **占问地经度必填**（真太阳时 R-T2）；`category` 走统一 9 类词表 |
| **3 真实反馈** | `feedback{outcome,outcomeDate,outcomeDetail,reliability,evidence}` | `outcome=应验` **必须给应期**；`尚未发生` **必须为 null**；可信度三档 |

### 强制标签与上限（决策三写进 Schema 常量）

```json
"status":        { "const": "hypothesis_under_validation" },
"confidenceCap": { "const": 0.6 }
```

**校验器会拒绝**缺标签、缺上限、`应验`无应期、`尚未发生`带应期、类别不在白名单的样本。

## 新增裁定

| 编号 | 裁定 |
|---|---|
| **R-C6** | **零模型必须保持"相位几何"**：打乱行星↔宫位会破坏"对冲⇒宫位差 6"这一结构 ⇒ 得到的 P 值**是同义反复**。测"相位是否携带信息"必须**分层（按相位类型×实际宫位差）**并**在层内置换** |
| **R-C7** | 分层结果：四分相差3 几何值 **16.7%**、对冲差6 几何值 **66.7%** —— 这是**映射表的算术常量**，任何分析都必须先扣除 |
| **R-C8** | **系统隔离是机检项**（`test/verify-isolation.mjs`）：确定性核心不得依赖实验层；跨系统产出强制 `hypothesis_under_validation` + `0.6` 上限 |
| **R-C9** | 成对样本的**出生时刻与占问时刻是两个不同时间，绝不可互相替代**（R-A3 的样本级落实） |
