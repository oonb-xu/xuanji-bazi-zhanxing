## 2 融合策略 v2：按用户要求重构为「分开跑 + 路由 + 互补」

用户裁定：① 两个系统**分开跑**；② **把互相缺失的结论补充**；③ **占星无法推算健康 → 健康类不让占星跑**。

### 实现（`rankYearsRouted`）

1. **两侧各自算逐年原始分**（八字侧只吃 `b_*` 特征，占星侧只吃 `a_*`，互不引用）；
2. **侧内 z 归一** —— 消除两侧量纲差（否则"分多"的一侧靠量纲赢）；
3. **按能力路由**：`SIDE_CAPABILITY = { 健康: {bazi:true, astro:false}, 其他: {bazi:true, astro:true} }`
   —— 健康类**占星侧完全不参与**；
4. **互补**：某年若一侧**没有任何特征触发**（对该年"无话可说"），
   则该年**只由另一侧定分，不做平均** —— 这就是"把互相缺失的结论补上"的落地。

**路由实测分布**（119 人 × 53 年 = 6,307 个年份实例）：

| 模式 | 实例数 | 占比 |
|---|---|---|
| 八字+占星（两侧都有话说） | 4,237 | 67% |
| **占星单侧互补** | **1,719** | **27%** |
| **八字单侧互补** | **262** | **4%** |
| 两侧沉默 | 89 | 1% |

→ **31% 的年份由单侧独立定分**，互补机制确实在工作。

### 🔴 但成绩说明了一个更难接受的事实

| 融合方案 | AUC | Top-5 | Top-10 | MRR |
|---|---|---|---|---|
| 等权 1:1 | 0.5000 | 10.1% | 26.9% | 0.098 |
| 按可靠度 1.75:1 | 0.5000 | 9.2% | 26.1% | 0.103 |
| 占星权重降到 0.5 | 0.5000 | 10.9% | 26.1% | 0.103 |
| **只用八字（占星权重 = 0）** | 0.5000 | **16.0%** | **38.7%** | **0.129** |
| *随机基线* | *0.5000* | *9.4%* | *18.9%* | — |

（n=120 子集；n=300 全量时八字单侧为 Top-5 12.4% / Top-10 52.8%，方向一致。）

**结论：在这批事件（全部是婚恋）上，只要掺入占星侧，成绩就下降；权重越低越好，降到 0 最好。**
即：**占星侧在本任务的应期信号处于噪声水平，其"补充"是负贡献。**

### 因此「融合」的正确定义（R-E12）

不是"两系统加权平均"，而是 **「按能力路由 × 按实测可靠度加权」**，且：

- **能力为 0 的类别**（健康 → 占星）：**权重直接置 0**，不参与；
- **实测可靠度 ≈ 噪声的侧**（本任务里的占星）：**在该类别上也置 0**，
  直到它被证明有独立信号为止（这正是"互补"的反面用法：**补的前提是自己先站得住**）；
- 只有两侧都过门槛，才谈加权 —— 且权重应来自**各自单侧的实测成绩**，不是先验拍的。

**这不是否定占星**，而是说：**它在"婚姻应期排序"这个具体任务上没测出信号**，
而在其他类别（如事业/迁移）可能不同 —— 那需要**分类别**测，不能靠一个总量结论外推。

## 3 事件类别联合拟合（用户要求"事件类别一起拟合"）

已实现为**类别特征**而不是按类别各拟合一套：

```js
CATEGORY_FEATURES = ['c_婚恋','c_健康','c_事业','c_财运','c_六亲','c_迁移','c_官非','c_意外','c_其他']
```

一套权重覆盖所有类别，靠这些 one-hot 特征让模型自己学"哪类事件该看重哪些信号"。
好处：① 参数不随类别数膨胀；② 类别间可**借力**（样本共享）；
③ 新增类别只需加一个特征，不必重跑整套拟合。

⚠️ **当前局限（诚实说）**：目前事件集**只有婚恋一类**（VedAstro 婚姻数据），
所以类别特征实际退化成了常数，**联合拟合的区分能力尚未被检验**；
健康类别更是**一个样本都没有** → **健康路由虽然实现了，但完全未被实战检验**。
下一步必须补事件类别（见 §4）。

## 4 新增裁定

| 编号 | 裁定 |
|---|---|
| **R-E12** | 融合 = **按能力路由 × 按实测可靠度加权**；某侧在**该类别**上未证明独立信号（单侧成绩不显著优于随机）时，**权重置 0**，不做"平均以求稳" |
| **R-E13** | 能力路由表须**显式登记**（`SIDE_CAPABILITY`）：占星不跑健康（古典占星看体质倾向，不做疾病诊断；五行-脏腑映射是八字侧的规则） |
| **R-E14** | 事件类别用**类别特征联合拟合**，不按类别各拟合一套；但**类别特征的有效性必须分类别验证**（当前仅婚恋一类 → 尚未验证，不得宣称有效） |
| **R-S8** | 数据源**必须登记** `data/SOURCES.md`：位置/出处/镜像/许可/字段/限制/可用性；**找不到的必须写"未找到"并附检索词**，禁止含糊 |

   celebrity50 的 `categories` 有健康类，但只有 50 人。**这是当前最该补的数据**。
