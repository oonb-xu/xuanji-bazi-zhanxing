# 三钟对齐：大运 / 流年 × 次运 / 行运

> 用户命题（2026-10-27）：
> 「把次运盘、行运盘…**做**，并且**试图和大运融合**（**副运类似于流年，但是年限有区别**，
> **你把不互通的部分当成补充内容**）」

---

## 1 四个钟的刻度（一切差异的根源）

| 体系 | 单位 | 周期 | 性质 |
|---|---|---|---|
| 八字**大运** | 10 年/步 | 80–100 年 | 干支序列，由月柱顺逆排 |
| 八字**流年** | 1 年 | 60 甲子循环 | 年干支 |
| 占星**次运（副运）** | **1 天 = 1 年** | 次运月亮 ≈27.3y / 次运太阳 ≈30y | **象征性推进**，非真实天象 |
| 占星**行运** | 实时 | 土星 29.46y / 木星 11.86y | **真实星历** |

**实测周期核对（最硬的证据）**

| 时钟 | 实测换格 | 理论 | 判定 |
|---|---|---|---|
| 八字大运 | 10.0 年/步 | 10 | ✓ |
| **次运月亮换座** | **2.3 年/次** | 27.3/12 ≈ 2.3 | ✓ |
| **行运土星换宫** | **2.4 年/次** | 29.46/12 ≈ 2.46 | ✓ |
| 行运木星换宫 | 1.1 年/次 | 11.86/12 ≈ 0.99 | ✓ |

> **四个钟周期互不相同 ⇒ 只能按「年份」对齐，不能互相换算。**

---

## 2 ★ 用户那句「副运像流年但年限有区别」的准确含义

| | 次运（副运） | 流年 |
|---|---|---|
| 刻度 | 1 年（1 天=1 年） | 1 年 |
| **机制** | **象征性推进**：出生后第 N 天的天象 | **干支循环**：60 甲子 |
| 来源 | 西方占星的方法论 | 中国历法 |
| **"同为一年"** | **只是刻度巧合，机制无关** | |

**⇒ 这两者绝不能互相替代。** 它们只是碰巧都用"年"作单位。

---

## 3 两层分离：互通 / 不互通

### 互通层（可对齐）

**共同坐标 = 公历年份。**

| 可对齐的事件 | 实测次数（1990–2050） |
|---|---|
| 大运换步 | 6 次 |
| 次运月亮换座 | 26 次 |
| 次运太阳换座 | 2 次 |
| 行运土星换宫 | 25 次 |
| 行运木星换宫 | 55 次 |

**对齐后能看到什么**：哪一年有**多少个钟同时换格**——这是纯结构事实，不含吉凶。

### 不互通层（**并排作补充，不合并**）

| 不可合并项 | 原因 |
|---|---|
| **「大运吉凶」vs「星盘庙旺强弱」** | 前者基于**日主扶抑**，后者基于**行星尊贵**——不同量纲，**只能并排，不能相加** |
| **次运 vs 流年** | 次运是**象征推进**（1 天=1 年），流年是**干支循环**；"同为一年"只是刻度巧合 |
| **行运 vs 次运** | 行运是**真实星历**，次运是**符号推进**；同一颗星在两盘里位置不同，**不可混用** |

## 4 实现

### 4.1 模块 `src/cross/timeline.mjs`

| 函数 | 作用 |
|---|---|
| `yearGanZhi(year)` | 年干支（1984=甲子） |
| `progressionAt(birth, age)` | **次运**时刻 = 出生后 N 天 |
| `transitAt(birth, age)` | **行运**时刻 = 出生后 N 年 |
| `buildTimeline(o)` | 生成逐年快照 + 换格索引 + 补充层 |

**逐年快照字段**
```
{ year, age,
  bazi: { dayun, dayunIndex, dayunRange, liunian },
  astro: { progressionDate, transitDate,
           progression: {太阳,月亮,水星,金星,火星,木星,土星},
           transit:     {木星,土星,天王星,海王星,冥王星},
           progressionIsDay, transitIsDay } }
```

### 4.2 API `POST /api/timeline`

```json
{ "at": "1990-03-15 12:00", "lng": 116.407, "lat": 39.904,
  "tz": 8, "gender": "男", "fromYear": 1990, "toYear": 2050, "limit": 40 }
```
返回 `range / rows / transitions / alignment / supplement / clockNote`。

### 4.3 前端「时序」页

四钟并排表：`年 | 岁 | 大运 | 流年 | 次运月亮 | 次运太阳 | 行运土星 | 行运木星 | 标记`

**任意一个钟在该年换格 ⇒ 整行高亮**，标记列写 `大运 / 次运 / 土星`。
下方分两块：「能对齐的（互通层）」「不能合并的（补充内容）」。

**实测**：1990–2050 共 61 年，**其中 27 年至少有一个钟换格**。

## 6 已知限制

| # | 限制 |
|---|---|
| 1 | **流年用公历年近似**，正式应以**立春**为界（跨年 1–2 月会偏） |
| 2 | 次运只做了**行星位置**，未做**次运相位**与次运宫位 |
| 3 | 行运只取 5 颗外行星，未做**行运相位**（对分相/四分相过本命盘） |
| 4 | 四钟「时间」的对齐只到**年**，未做月/日级 |
| 5 | **不含吉凶判定**——这是刻意的：两层量纲不可合并 |

**⚠️ 纪律**：本页只输出**结构事实**（哪年换了哪个格），不下吉凶结论。
