# 互容结构推演（古典尊贵体系）

> 用户 2026-10-25 命题：
> 「把次运盘、行运盘、星盘的**互容结构**进行推演…这个有**内在的分级**，分别是**庙旺互换**、**庙旺对三分**」
> 「**所有相位都会输送能量**。例如男命木星虽然陷落，但和月亮对冲，月亮巨蟹，同时也是木星的擢升，也能为木星输送能量」

---

## 1 古典依据（已核对原文）

**Masha'allah《论接待》(On Reception) 第一章**，Benjamin Dykes 译本（[skyscript 节选](https://www.skyscript.co.uk/masha_allah_receptions.html)）：

| 原文要点 | 本实现 |
|---|---|
| 「接待来自**擢升与庙**」 | 核心判定以庙/旺为主，三分次之 |
| 「若土星在白羊、火星在摩羯…**火星接待土星**（因土星在火星的庙），而**土星接待火星**（因火星在土星的庙）」 | 互容 = 彼此都在对方庙中 → 本实现的 **I 级** |
| 「**擢升**在王国之事上比庙**更有权威**」 | 旺接待的权重单独保留（II 级） |
| 「若太阳在白羊、土星在天秤…**彼此都不接待对方**，则生**怨憎与悖逆**」 | ★ **本实现独立复现了这个案例** → `none` |
| 「若在**四分相或对冲**，主劳苦、错误、焦虑；在**三分、六分、合相**，主顺遂」 | 相位带 `smooth` 标记，但**都输送能量** |
| 「合相/对冲/三分/四分/六分皆可成接待」 | 五种相位全部参与判定 |

## 3 ★ 分级（用户指定）

| 级 | 名称 | 条件 | 权重 |
|---|---|---|---|
| **I** | **庙庙互换** | 彼此都在对方**庙**中 | 1.00 |
| **II** | **庙旺互换** | 一方庙、一方旺 | 0.85 |
| **III** | 旺旺互换 | 彼此都在对方**旺**中 | 0.70 |
| **IV** | **庙旺对三分** | 一方庙/旺，另一方仅**三分** | 0.45 |
| — | 单向接待 | 只有一方在对方尊贵中 | 0.30 |
| — | 无互容 | 彼此都不在对方尊贵中 | 0.00 |

### ★ 一条必要的守卫：失势星不做主人

> **若某星在此星座处于「陷/落」，则此地不作为它的待客之所。**

理由：一个星球不会在自己的**败落之处**好客。
**这条守卫让引擎自动复现了古籍案例**：太阳@白羊（土星的落）× 土星@天秤（太阳的落）→ `none`，与 Masha'allah「彼此都不接待对方，则生怨憎」完全一致。

## 4 相位输能（用户核心命题）

**规则**：
1. 每颗星先算**自身尊贵分**（−5…+5）
2. 对每条相位，比较两星尊贵差
3. **能量从尊贵高的一方流向低的一方**
4. 流经互容的相位，**流量按互容等级加成**（互容让相位"通"）
5. ★ **若弱方身处强方的尊贵之中（"携带尊贵"），流量再 ×1.5**
   —— 这就是用户说的「月亮巨蟹（木星的擢升）能为落陷的木星输送能量」

**流量公式**
```
amount = |尊贵差| × 0.12 × 相位权重 × orb衰减 × (1 + 互容等级×0.6) × [携带尊贵 ? 1.5 : 1]
相位权重：合相 1.00｜三分 0.85｜对冲 0.75｜四分 0.70｜六分 0.60
```

## 5 实测

### 5.1 用户例子（机制核对）

| 项 | 值 |
|---|---|
| 木星@摩羯 | **落 −5** |
| 月亮@巨蟹 | **庙 +5**（且巨蟹是木星的**旺**） |
| 月亮在木星尊贵中？ | **旺** ✓ |
| 木星在月亮尊贵中？ | 摩羯是月亮的**陷** → 否（守卫拦下） |
| 判定 | **单向接待（0.30）** |

**⇒ 月亮携带着木星的旺去对冲木星，用户的说法成立。**

### 5.2 样例B（某市 1992-08-20 12:00）— 输能 Top4

```
月亮(+4) → 金星(-5)   三分相  量1.156  ★携带尊贵 [庙旺对三分]
太阳(+5) → 天顶(0)    合相    量0.992  ★携带尊贵 [单向接待]
太阳(+5) → 北交点(0)  三分相  量0.892  ★携带尊贵 [单向接待]
火星(0)  → 金星(-5)   四分相  量0.729  ★携带尊贵 [单向接待]
```

**金星在处女落(−5)**，却同时从**月亮**（金牛是金星的庙，月亮在此旺）和**火星**（四分相）获得补给。
**四分相也在输能** ⇒ 印证「所有相位都会输送能量」。

**该盘互容 10 条：单向接待 9 / 庙旺对三分 1。**

### 5.3 古籍案例复现

| 组合 | 结果 | 古籍 |
|---|---|---|
| 太阳@白羊 × 土星@天秤 | **none 无互容** | 「彼此都不接待对方，则生怨憎与悖逆」✓ |
| 月亮@白羊 × 火星@巨蟹 | **I 庙庙互换** | 「火星接待月亮…互相接待」✓ |

## 6 次运盘 / 行运盘

模块已支持**任意盘对象**（本命 / 次运 / 行运）直接调用 `aspectEnergyFlow(chart)`。
`progressionDate(birthAt, ageYears)` 实现次运：**1 天 = 1 年**。

**用法**：把次运或行运时刻喂给 `computeNatal` 得到盘，再走同一套互容/输能逻辑 —— 口径完全一致，不需要另写规则。

## 7 已知限制

| # | 限制 |
|---|---|
| 1 | 只用了**庙/旺/三分**三种尊贵，**未含界(term)、面(face)** —— 用户的分级也只要求这三层 |
| 2 | 外行星（天王/海王/冥王）**无古典尊贵**，在本体系中只能是"纯负数方"（无庙旺可依） |
| 3 | 输能公式的系数（0.12 / 1.5 / 0.6）是**先验**，未经事件校准 |
| 4 | 次运/行运只提供接口与日期换算，**未接入自动轨道计算** |
| 5 | 昼/夜盘未区分（三分性三主同列）—— 严格做法需先判日盘/夜盘再取昼主或夜主 |

**⚠️ 纪律**：以上一切是**结构描述**，不是吉凶判断；权重未经真实结局校准。
