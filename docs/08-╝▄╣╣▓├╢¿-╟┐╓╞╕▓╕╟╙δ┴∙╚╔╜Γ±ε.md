## 0 执行原则（重要）

本轮是**人工裁定覆盖引擎派生值**，处理方式固定为三条，不可简化：

1. **显式锁定，不静默改写**：锁定值写入 `manual_overrides`，带 `ruling / lockedBy / ts / reason`。
2. **派生值留痕不删**：对拍表的备注列保留「引擎派生值 X」，`_override_log` 记录 前值→后值→影响。
3. **锁定后必须重跑下游**：权值改动 → 重算 `strengthVerdict` 与 `yongJiShen`；干支改动 → 重算十神。

> 这与项目既有纪律一致：本引擎从不静默采信任一方（无论是 DB 还是自己的算法）。

## ARCH-1 命宫锁定为「己酉」

| 项 | 值 |
|---|---|
| 字段 | `tai_ming_shen.minggong` |
| 引擎派生（R-B2 等式） | 和 = 月支子(1) + 时支申(9) = 10 → 14−10 = 4 → 卯 → 五虎遁（丁年壬寅起）→ **癸卯** |
| 裁定锁定值 | **己酉**（十神：七杀 + 偏印） |
| 处理 | 状态记为 `人工锁定`（对拍第 4 种状态），引擎派生值 癸卯 留在备注 |
| 影响 | 命宫十神由「比肩」改为「七杀」；Part3/Part5/Part8 的命宫参照随之改变 |

**诚实备注**：本引擎穷举了常见命宫起法（月支数+时支数 / 寅=1 起 / 农历月 / 26−和），均得 卯或巳，未见得酉；
`己酉` 恰等于本引擎用**身宫**公式（和=10 ≤12 → 取和 → 酉）所得。是否属于某一流派另法，需裁定方给出等式，
届时可按「流派变体」实现为参数，而不是硬编码锁定。

## ARCH-2 火权重锁定为 3.0 + 修正 R-B1

| 项 | 值 |
|---|---|
| 字段 | `bazi_basic.score.fire` |
| 引擎派生（修正前 R-B1） | 丁透 1.0 + 巳本气丙 1.0×0.5（亥巳冲腰斩）= **1.5** |
| 裁定锁定值 | **3.0**（财星受困但有强根；底线 ≥2.5） |
| 处理 | `manual_overrides` 写入 `adjusted.火 = 3.0`，随后**重跑**强弱与用忌神 |

**并行的规则修正 R-B11（相冲分级）**——不再一刀切腰斩，按柱距分级：

| 柱距 | 例 | 本气系数 | 中/余气系数 |
|---|---|---|---|
| 1（相邻） | 年月 / 月日 / 日时 | ×0.5 | 归零 |
| 2（隔一柱） | **年日** / 月时 | ×0.75 | ×0.5 |
| 3（隔两柱） | 年时 | ×0.9 | ×0.75 |

亥(年)–巳(日) 属 distance=2 → 本气 ×0.75。**R-B11 单独作用时**火 = 1.75（仍未到 3.0）；
3.0 只有锁定层能给到。二者的差别是「模型能推的」与「架构师认定的」之差，故两者都保留。

**锁定 + R-B11 后的五行修正权重（重跑结果）**

| 五行 | 引擎修正权重 | DB 值 | 差 |
|---|---|---|---|
| 水 | **6.5** | 6.5 | 0 |
| 金 | **3.2** | 3.2 | 0 |
| 火 | **3.0**（锁定） | 3.0 | 0 |
| 土 | **0.45** | 0.4 | +0.05 |
| 木 | **0.25** | 0.5 | −0.25 |

→ 印比占比 **0.724**，判 **身旺**（非从格，与 `geju_boundary` 一致）。

## 已知未决

1. **ARCH-1 的等式缺失**：锁定值 己酉 无法由任何已知公式推出，目前是硬锁定。若要变成可复算的流派参数，需给出等式。
2. **ARCH-2 的 3.0 不可复算**：R-B11 最高只能给到 1.75（去掉冲损则 2.0）；3.0 依赖锁定层。若希望 3.0 可复算，需改权重模型（例如为「木通关生火」计加成，可推到 2.5 命中裁定底线）。
3. **R-B11 的系数（0.75 / 0.9）**是裁定值，非规则表给定。
4. **六壬接口**已解耦并跑通，但占课结果不写回任何库（无 event 记录），如需留痕要另建 `divination` 集合。
5. 锁定层目前支持 `score.*` 与 `tai_ming_shen.*` 两类；其余字段（如 `bazi_relations.*`）尚不能锁定。
