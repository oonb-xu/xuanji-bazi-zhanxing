## 8.1 每次推演后必须执行

| 步骤 | 实现 | 落库集合 |
|---|---|---|
| ① 提取「八字十神 ↔ 星盘行星」对应 | `correspondences()` —— 用 5.1 表逐行解析，十神侧取本命局权重，行星侧取宫位+星座+**庙旺陷落** | `correspondence` |
| ② 验证 `bazi_relations`（冲合害）与 `astro.aspects`（硬相位）是否共振 | `resonance()` —— **复用 Part 6 的 6.1 映射与破坏值**，不另立一套；硬相位无对应八字关系者计入 `unmatched` | `resonance` |
| ③ 输出三类结论 | `renderDbDiscovery()` | `proposal` / `run` |

三类输出的确切定义：
- **【本次新发现】**：本次命局内 `十神强弱 × 行星尊贵` 判为共振/背离的条目，以及冲合害×硬相位的命中项。
- **【数据库更新建议】**：`rules`（共振映射）与 `jishen_alert`（破坏值 ≥2.0 的摩擦式）。
  **只进 `proposal` 集合、状态 `pending-human`，绝不自动写进目标集合**——自动写等于自己造规则（见裁定 R-D10）。
- **【待验证猜想】**：6.7 的 `pending` 项 + 本引擎生成的可证伪命题（胎元↔北交点、命宫↔太阳/上升、身宫↔月亮、十神↔庙旺同步率）。

## 8.2 长期迭代

- **新映射追加到 `rules`**：走 6.7 映射库的**证据链**（`observe()`），不是直接改结论；
  `verified` 仍需 ≥3 张不同命盘且 0 反例。
- **每 10 次推演复盘矛盾点**：`contradictionReview()` 扫描 `rules`，把「有反例 / 证据混杂 / 零支持」的条目
  连同原因写入 `review` 集合并标注 **「需人工验证」**。轮次 = `run` 集合的事件数，第 10/20/30… 轮自动触发；
  `--kb-review` 可随时手动触发。

## 知识库结构（只追加事件流，事件溯源）

| 文件 / 集合 | 内容 |
|---|---|
| `data/mapping-library.jsonl`（**rules**） | 6.7 的映射规律（claim/evidence/verdict），本协议只读 JOIN + 追加证据 |
| `data/kb.jsonl` → `run` | 每次推演的开始事件（轮次计数） |
| `data/kb.jsonl` → `correspondence` | 十神↔行星对应（含庙旺陷落与一致性判定） |
| `data/kb.jsonl` → `resonance` | 冲合害 × 硬相位共振（命中项、得分、等级） |
| `data/kb.jsonl` → `proposal` | 数据库更新建议 + 人工裁决事件 |
| `data/kb.jsonl` → `review` | 矛盾复盘（含「需人工验证」标记） |

> 设计同 `dsh-agent-fabric` 的 vault：**只追加、可回放、状态由事件推出**，历史不可就地改写。

## 实现裁定

| 编号 | 未定义处 | 裁定 |
|---|---|---|
| R-D10 | 「在 `jishen_alert` 中追加」是否自动执行 | **不自动**。规则表 8.1 原文是「数据库更新**建议**」；自动写库等于未经用户确认地自造规则，与「禁止自行编造规则」「单盘不算已验证」冲突。一律进 `proposal`(pending-human)，由 `--kb-accept/--kb-reject` 裁决 |
| R-D11 | 共振得分 → 等级 | 得分 = Σ 各命中项的破坏值；≥6 高 / ≥3 中 / >0 低 / =0 无 |
| R-D12 | 十神侧与行星侧如何判「一致」 | 十神强度 = 该组十神在本命局的权重和（天干 1.0 + 藏干带权）；本组均值 ×1.2 以上为强、×0.6 以下为弱，其余为中。行星侧用**庙旺陷落分**（庙+2/旺+1/中0/陷−1/落−2）→ 强/中/弱。同号 → **共振**，反号 → **背离**，任一侧为中 → **中性**，缺盘或无星 → **不可比** |
| R-D13 | 十神组简写的展开 | 食伤=食神+伤官；印星=正印+偏印；财星=正财+偏财；比劫=比肩+劫财；官杀=正官+七杀；羊刃→劫财；用神/忌神→取该五行的修正权重；命宫/身宫/年柱…→取对应柱权重（干 1.0 + 藏干和） |
| R-W6 | 庙旺陷落表 | 庙=守护星座；陷=庙之对宫；旺取通说；落=旺之对宫。**现代三王星的旺/落各家不一**（海王旺狮子或射手、冥王旺白羊或狮子），本表取通说并置 `disputed=true`，异说仅记录不参与判定 |

## 已知未决

1. **`proposal` 的裁决目前是命令行的**（`--kb-accept/--kb-reject`），没有 UI；裁决后也**不会**自动把条目写进 `jishen_alert`
   —— 目前 `jishen_alert` 只是被建议的目标名，尚无消费方。要不要真的物化成一张可查询的告警表，等用户裁定。
2. **一致性的阈值**（×1.2 / ×0.6）是 R-D12 的裁定值，非规则表给定；改它会改变全部共振/背离结论。
3. **命宫/身宫的度量是近似**（以月柱/时柱权重各 ×0.5 代），因为命宫身宫本就无「权重」概念。
4. **同步率需要跨盘统计**才有意义；当前单盘只报本次比值。
5. 复盘只扫 `rules`；`correspondence` / `resonance` 的历史矛盾尚未纳入扫描范围。
