## 1 ⚠️ 任务 B 仍留着一处必须指出的问题

任务 B 写：「数据源 B：使用 Astro-Databank 检索**同一年份**出生的 AA 级名人」——
**这仍是日期映射**（只是把"同一天/同 30 天"换成"同一年"），与任务 A 的"结构量对比"目标相冲突。

**更关键的是第二处**：「只要两侧拓扑**同构**即视为结构对齐」——
**没有零模型的"同构"是巧合生成器**：
- 六壬三传的拓扑型很少（实测 7 类，见 §3），名人盘数量上万
- ⇒ 每个课例都会**必然**找到大量"同构"的名人盘，**这个数字本身没有信息量**

**必须补的一步**：任何"同构率"都必须与**随机配对的同构率**并列，
且随机化必须在**正确的层级**上做（见 §4 的陷阱）。

## 4 ★ 一个看起来显著、但极可能是几何假象的结果（必须记录）

**发现**：500 盘、**7,176 条刑/冲边**中，"两端行星所在宫的五行呈**克**关系"占 **42.20%**，
而"随机两个五行呈克"的朴素基线是 **40.0%** ⇒ **z = 3.80，p ≈ 5.1e-5（高度显著）**。

**为什么不能采信（立刻自查出的原因）**：
**对冲/四分相两端的黄经差被角度锁死**，而五行由所在宫决定 ⇒ "克"的比例**本就由几何决定**，不是随机的 40%：

| 相位 | 宫位偏移 | 五行关系为「克」的比例（**几何决定**） |
|---|---|---|
| **对冲**（180°） | ±6 宫 | **4/6 = 66.7%** |
| **四分相**（90°） | ±3 宫 | **2/12 = 16.7%** |

⇒ 观测到的 42.2% **正落在两种相位的几何期望之间**，
**朴素基线（40%）是错的基线**，所谓"显著"来自**基线选错**，不是来自信息。

**这一步的方法论意义**：**零假设必须在正确的层级上构造** ——
占星相位与五行的关系里，**角度已经决定了宫位偏移**，所以打乱的对象**不能是"五行"，而必须是"行星与宫位的对应"**。

## 5 能力核查（要求 3 的答复）：引擎现在能不能同时调用？

| 能力 | 状态 | 位置 |
|---|---|---|
| 六壬三传计算（含每传五行） | ✅ 有 | `deriveSanChuan().chain` |
| 六壬三传 → 有向图 | ✅ **本轮新建** | `sanChuanTopology()` |

| 星盘 → 有向图 | ✅ **本轮新建** | `aspectTopology()` |
| 黄经 → 宫 → 五行 | ✅ 有（复用 L2） | `wuxingOfLon()` |
| 统一签名 / 形状 | ✅ **本轮新建** | `topologySignature()` / `topologyShape()` |
| **冷启动侧 A（古籍课例）** | ✅ 有 65 例（A 级 21） | `data/liuren/cases.jsonl` |
| **侧 B（名人盘）** | ✅ 有 15,790 | `data/vedastro/` |
| **两系统的「同时刻」成对数据** | ❌ **没有** | 这是方案1 的真瓶颈 |
| **同构判定的零模型** | ❌ **未建**（§4 未完成） | 下一步 |

**结论**：**两侧的图都能独立算出来了（能力齐备）**；
**但"结构对齐"缺两样东西** —— ① **同时刻成对数据**；② **正确层级的零模型**。
**没有这两样，"对齐率"只是一个没有对照的数字。**

## 6 新增裁定

| 编号 | 裁定 |
|---|---|
| **R-C1** | 统一拓扑语言：**节点 = 五行**、**边 = 生/克/比和**（有向）；跨系统比对用 `topologyShape()`（剥离具体五行） |
| **R-C2** | 相位 → 关系映射以**实测字符串**为准：`合相→比和`、`对冲/四分相→克`、`三分相/六分相→生`、`梅花相→不参与` |
| **R-C3** | 任何"结构同构/对齐率"**必须与随机配对的同构率并列**；**禁止**只报同构率 |
| **R-C4** | **零假设必须在正确层级构造**：占星侧的角度**已锁定宫位偏移** ⇒ 打乱对象是"行星↔宫位对应"，**不是**"五行"（否则基线错误，实测会造出假显著 z=3.80） |
| **R-C5** | 无「同时刻成对数据」时，结构对齐结论**只能标为"猜想与验证"**（用户 Task C 第 3 条），不得升级置信度 |
