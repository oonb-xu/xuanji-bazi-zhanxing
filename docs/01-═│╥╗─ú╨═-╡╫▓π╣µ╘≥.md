# 阶段一 · 底层规则：统一推演模型（Unified Divination Algebra, UDA v1.0）

> 目标：把「中国玄学（以六壬、奇门、八字为代表）」与「西方占星学（本命/卜卦盘）」还原到
> **同一套底层代数**上。此文件是公理层，任何具体术数（含本仓库 `大六壬` 子项目）都必须是它的一个实例化。
> 原则：**禁止口诀作为规则来源**。口诀只能作为"待反编译的观察数据"，最终必须落成显式等式。

## 0. 为什么可以统一（同构事实）

| 维度 | 中国玄学 | 西方占星 | 同构关系 |
|---|---|---|---|
| 时间粒度 | 年/月/日/时四柱 | 年/月/日/时（同） | 都是**干支/儒略日**的离散化，同一 `JD` |
| 空间分基 | 十二辰（30° 一等分） | 黄道十二宫（30° 一等分） | **同一个 12 分环**，只差零点 |
| 太阳坐标 | 月将 = 太阳所躔之次 | 太阳星座 | **同一个量** `λ☉` |
| 盘面 | 地盘固定 / 天盘随月将加时旋转 | 宫位固定 / 行星按黄经落宫 | **都是 `C₁₂` 上的平移** |
| 关系 | 五行生克（5 元上两个循环） | 相位（角度差映射） | **都是 `ρ: Δ → 语义`** 的二元关系 |
| 语义算子 | 十二天将 | 十大行星 / 十二宫 | **都是贴到盘上的符号标签** |
| 推演 | 三传链（起因→过程→结果） | 宫主星链 / 相位链 | **都是有向图上的路径评分** |

结论：统一模型的骨架 = **环 + 旋转 + 映射 + 关系 + 路径**。

## 1. L0 时间基座

给定同一时点 `t`（含时区与真太阳时修正）：

```
JD   = 儒略日(t)
λ☉   = 太阳视黄经(t) ∈ [0,360)
气   = 最近的十二中气（太阳黄经 = 270 + 30k 的等分点）
柱   = 干支纪年/月/日/时（由 JD 与节气决定）
时辰 = floor(((H + 1) mod 24) / 2) ∈ {0..11}
```

**关键等式（中西共用的唯一时间入口）**

```
λ☉ 的 12 分索引  s = floor(λ☉ / 30)          # 0=白羊(春分点起)
```

- 中国侧：`月将` 与 `s` 一一对应（见 §2）。
- 西方侧：`太阳星座` = `s`。
- 所以 **"换将"与"太阳换座"是同一个事件**，都发生在 `λ☉ ≡ 0 (mod 30)`。

> 实现：`tyme4ts` 提供节气与四柱；`λ☉` 可用同一节气表反解（每个中气相差 30°）。

## 2. L1 分基与零点

十二分环上存在**两个不同的零点**，这是全部"中西方换算"的唯一难点：

| 坐标系 | 零点定义 | 十二支/宫对应 |
|---|---|---|
| 地盘（方位） | `子 = 正北 = 冬至点 = λ☉ 270°` | `L(d) = 270 + 30·index(d)` |
| 十二次（月将） | `戌 = 降娄 = 白羊 = λ☉ 0°` | 见下表 |

由此得到两条**可验证的等式**（本仓库 `test/verify.mjs` A 组即在验证它们）：

```
d☉ = ((λ☉ − 270) / 30) mod 12        # 太阳在地盘上的方位索引
月将索引 = (10 − floor(λ☉/30)) mod 12 = (1 − d☉) mod 12
```

## 3. L2 盘面 = 环上的平移

**静盘（地盘 / 宫位）** 固定：`D[i] = i`。

**动盘**由一次旋转生成：

```
中国侧：天盘 = 月将加于占时   →   T = D ⊕ r,  r = (占时 − 月将) mod 12
西方侧：行星按黄经落宫       →   落宫索引 = floor(((λ − 宫头λ) + 360) mod 360 / 30)
```

两者都写作：`动盘(x) = x + r`（`C₁₂` 上的平移）。旋转量 `r` 是**唯一的局参数**。

**四课 / 命盘**则是同一个盘的**取点规则**：

```
四课 = (干寄宫, 支, 以及它们各自的上神×2)      # 对 D 的两次迭代 f(x)=T[x]
本命盘 = (十行星λ, 十二宫头λ, 上升/中天)      # 同一数据的不同投影
```

> 结论：`四课`不是独立结构，而是"动盘上以日干支为种子的两步轨道"。这条把六壬纳入统一代数。

## 4. L3 关系代数 ρ

### 4.1 中国侧：五行生克（5 元上的两个有向循环）

```
生：木→火→土→金→水→木
克：木→土→水→火→金→木
```

### 4.2 西方侧：相位（360 上的角度差 → 类别）

```
Δ = |λ₁ − λ₂| mod 360,  取 min(Δ, 360−Δ)
合0° / 六分60° / 刑90° / 三分120° / 对分180°
```

### 4.3 统一形式

两者都是 `ρ: Δ ∈ G → {助益, 张力, 中性}`，`G` 分别为 `C₁₂` 与 `C₃₆₀`：

| | 助益 | 张力 | 中性 |
|---|---|---|---|
| 五行（Δ∈C₅ 五行序） | 生 | 克 | 同类 |
| 相位（Δ∈C₃₆₀） | 三分120/六分60 | 刑90/对分180 | 半六分30 |

**统一判据**：`ρ(Δ) = +1 (助) / 0 (中) / −1 (损)`，可直接累加为链路得分。
这是"三传做功链条"与"相位链"共用的同一个函数签名。

## 5. L4 符号算子（语义层，非规则层）

规则层只产出**结构**（哪个支、乘哪个将、走哪条链）；符号层负责**贴语义**。

| 中国 | 西方 | 角色 |
|---|---|---|
| 十二天将（贵人…天后） | 十大行星 | **状态算子**：修饰所临之宫 |
| 十二支 / 五行 | 十二宫 / 四元素 | **能量类型** |
| 神煞 | 阿拉伯点 / 恒星 | **稀疏标记** |

已冻结的天将分类（本仓库 `src/render.mjs`）：

```
吉：贵人 青龙 六合 太常
凶：白虎 螣蛇 朱雀 勾陈
暗昧：玄武 天空
```

> 注意：**分类是语义层约定，不是规则层等式**——它可被整体替换而不影响 L0–L3 的任何计算。

## 6. L5 推演 = 有向图路径

```
中国侧：三传链  初传（起因） → 中传（过程） → 末传（结果）
西方侧：宫主星链 / 相位传递链
```

统一算法：

```
score(path) = Σ ρ(wuxing(xᵢ), wuxing(xᵢ₊₁))     # 用 §4.3 的 ±1/0
tag(path)   = 通关（先克后生） | 死克（连克） | 顺生（连生）
```

**起链规则（中国侧，即"三传"）**是唯一的系统专属部分，按固定优先级选取：
`贼克 → 比用 → 涉害 → 遥克 → 昴星`，遇 `伏吟/返吟/别责/八专` 转专用规则。

## 7. 分层契约（任何新术数接入必须实现的接口）

```ts
interface DivinationModule {
  L0: (t: Time) => { JD, λ☉, 节气, 柱, 时辰 }        // 必须复用同一时间核
  L1: (t: Time) => { 主坐标, 主索引 }                 // 月将 / 太阳星座 / 局数
  L2: (L1) => { 静盘, 动盘, rotation }                // 平移量 r
  L3: (盘) => Relation[]                             // 生克 / 相位
  L4: (盘) => SymbolMap                              // 天将 / 行星
  L5: (L3,L4) => { 链, 分类链, 置信度 }               // 三传 / 宫主链
}
```
