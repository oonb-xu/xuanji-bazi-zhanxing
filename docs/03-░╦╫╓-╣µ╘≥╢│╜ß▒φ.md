# 八字 · 规则冻结表 v1.0 + Part 5 交叉修正（阶段一子项目 · 第二实例）

来源：用户给定的「八字底层推演编译器」规则（Part 1–5）。本文件为**规则唯一真源**，
`src/bazi/*` 与 `src/cross/*` 必须逐条对应；任何偏离在「实现裁定」中写明理由与依据。

## Part 1 五行生克引擎
- 1.1 天干五行：甲乙木 / 丙丁火 / 戊己土 / 庚辛金 / 壬癸水 → `GAN_WU_XING`
- 1.2 地支五行：寅卯木 / 巳午火 / 辰戌丑未土 / 申酉金 / 亥子水 → `ZHI_WU_XING`
- 1.3 生：木火土金水木；克：木土水火金木 → `SHENG` / `KE`
- 1.4 日主强弱权重：得令 3 / 得地 2 / 得势 1 / 被克泄耗 −1～−2 → `dayMasterStrength()`

## Part 2 地支藏干引擎
- 藏干表（12 支，本气/中气/余气）→ `HIDE_GAN`（**逐字照抄规则表**）
- 2.1 权重 1.0 / 0.5 / 0.2 → `HIDE_WEIGHT`
- 2.2 互动：透干 ×2；被冲本气 ×0.5、中余气归零；被合本气一半转向合化五行 → `hiddenStems()`

## Part 3 胎元 / 命宫 / 身宫
- 3.1 胎元 = 月干进 1、月支进 3 → `taiYuan()`
- 3.2 命宫：和 = 月支数 + 时支数（子=1）；和≤14 → 14−和；和>14 → 26−和 → `mingGong()`
- 3.3 身宫：和≤12 → 和；和>12 → 和−12 → `shenGong()`
- 天干一律以**年干起五虎遁**（甲己丙寅…戊癸甲寅）定之 → `wuHuDun()`

## Part 4 输出格式
`src/bazi/render.mjs`：排盘基础 / 五行力量分析 / 地支藏干拆解 / 做功链条推演 / 胎命身共振 / 落地建议

## Part 5 占星 ⟷ 八字交叉修正
- 5.1 行星→十神（13 条）→ `PLANET_TO_SHISHEN`
- 5.2 宫位→八字宫位（12 条）→ `HOUSE_TO_BAZI`
- 5.3 相位→刑冲合害（6 条）→ `ASPECT_TO_RELATION`
- 5.4 修正规则 A–E（16 个 IF）→ `calibrate()`，测试逐条隔离验证 16/16
- 5.5 输出：交叉验证表 5 行 + 胎命身三星对照表 3 行 + 跨系统落地建议

**星盘输入 schema**（`examples/astro-sample.json`）：
```json
{ "planets": { "太阳": {"sign":"摩羯","house":7,"deg":15}, "…": {} },
  "aspects": [ {"a":"冥王星","b":"太阳","type":"对冲"} ] }
```
`type ∈ 合相|对冲|四分相|三分相|六分相|梅花相`；`sign` 用中文星座名，`house` 用 1–12。

## 实现裁定（规则表未定义处，显式补全）

| 编号 | 未定义处 | 裁定 |
|---|---|---|
| R-B1 | 藏干"被合/被冲"的量化口径 | 被冲：本气 ×0.5、中余气归零；被合：本气一半（50%）转入合化五行，余半保留本五行；三合成局：局五行 +1.0 |
| R-B2 | 命宫得 0（和=14）时取何支 | 取 12（亥）。注：标准古籍等式与第三方库 tyme4ts 相差固定 6 位（相冲），**规则表等式优先**，IR 同时保留库值 `meta.lib.mingGong` |
| R-B3 | 用神/忌神如何选 | 扶抑法：身弱/中和偏弱 → 候补 [印, 比劫] 取原局**最缺**者；身旺/中和偏旺/从弱 → 候补 [官杀, 财, 食伤] 取**最缺**者；从强 → 用同我、忌克泄耗。忌神 = 对立集合中权重最旺者 |
| R-B4 | 强弱判定的阈值 | 印比占比 r：≥0.80 从强；≤0.20 且日主无根 从弱；≥0.55 身旺；≤0.45 身弱；其间为中和偏旺/偏弱 |
| R-B5 | "得令"是否含月令生我 | 同我 = 3；生我 = 2（规则表只给 3，生我按 2 计并单列） |
| R-B6 | Part 5 硬相位的范围 | 对冲 / 四分相为硬相位；合相在涉及土/冥/天/海/火/日/月时按硬相位计 |
| R-B7 | 5.1–5.3 映射表在计算中的角色 | 表是**语义层**：不由其反推规则；修正逻辑只按 5.4 的 IF 执行 |
| R-B8 | 格局判定 | 建禄格 = 月支为日主禄位；缺官杀 = 全局（干+藏干）无官杀五行；财星受困 = 财五行修正权重 < 1.0 |

## 已知未决

1. **命宫口径分歧**：规则表等式与 tyme4ts 固定相差 6 位。三者取一需用户裁定（当前=规则表优先）。
2. **用神/忌神非唯一**：规则表未给等式，R-B3 是扶抑法的一种确定性口径，改变口径会改变 Part 5 全部 B/C 组结论。
3. **真太阳时**：定柱用钟表时，未做经度时差与均时差修正（与大六壬模块同一缺口）。
4. **占星侧仍需外部输入**：本模块不产生星盘，只消费 `examples/astro-sample.json` 形态的结构化数据；西方占星盘模块（`modules/western`）尚未实现。
5. **Part 5 的 5.1/5.2/5.3 映射表用于展示**：目前是语义对照，未参与数值计算。
