## 1 韩式八字（39,494 人）—— 本项目第一个 100% 机检的大规模验证

数据：[`brandonrhie/korean-public-figures-saju`](https://huggingface.co/datasets/brandonrhie/korean-public-figures-saju)，
39,494 行、0 空出生日期、37,433 有职业，**日精度**。

### 1.1 三柱排盘对拍（与数据集自带的三柱逐条比）

| 柱 | 一致 | 一致率 |
|---|---|---|
| 年柱 | 39,064 / 39,494 | **98.911%** |
| 月柱 | 39,015 / 39,494 | **98.787%** |
| 日柱 | 39,110 / 39,494 | **99.028%** |
| **三柱全对** | **38,972 / 39,494** | **98.678%** |

**不一致的成因（已逐条看样例）**：

| 类型 | 样例 | 判定 |
|---|---|---|
| **立春换年边界** | `1971-02-04 我庚戌 vs 库辛亥`、`1999-02-04 我戊寅 vs 库己卯` | 边界口径差（我按立春换年），**非错** |
| **节气换月边界** | `1994-11-07 我甲戌 vs 库乙亥`（立冬）、`2011-04-05 我壬辰 vs 库辛卯`（清明） | 同上 |
| **库值缺失** | `1892-03-15 我丙午 vs 库（空）`、`1894/1899` 同类 | 数据集早期人物字段为空 |

→ **本引擎的排盘在一个第三方独立算出的 39,494 盘数据集上通过 98.7% 完全一致**，
不一致全部落在"换柱边界"与"库值缺失"两类可解释情形。

而 `occupations_raw` **含逗号** → **整行列错位**（日支读成 `undefined`、年干读成布尔 `True`），
**且不报错**，一度报出"日柱 0.000% 一致"。改用 `csv-parse` 后恢复正常。

### 1.2 胎元（可算）与命宫/身宫（**不可算**）

| 项 | 结论 |
|---|---|
| **胎元** | ✅ **39,110 条算出，60 种全部出现**（分布 700–780/种，均匀）。公式：**月干进一位、月支进三位**（只需月柱） |
| **命宫 / 身宫** | ❌ **不可算** —— 两者公式都要**时支**，而该数据集**无出生时刻** |
| 时柱 / 大运 | ❌ 同样不可算 |

**裁定 R-K1**：日精度数据上**只允许评估年/月/日三柱与胎元**；
凡涉及**时柱、大运、命宫、身宫**的规则一律**不得**在此数据集上评估（本库中这些字段一律写 `null`，**不编造**）。
→ 本地库已落：`data/korean/korean-db.jsonl`，**39,494 条 / 14.2 MB**，含三柱 + 胎元 + 职业 + 地点。

## 2 占星时序盘：8 种全部实现（`src/western/timing-charts.mjs`）

| 技法 | 实现 | 口径与验证 |
|---|---|---|
| **行运** | 已有（`event-fit.mjs` 的全局行运表） | 外行星 1890–2026 每 20 天，全局复用 |
| **次限**（Secondary） | `secondaryProgressed(birth, age)` | **1 天 = 1 年** |
| **三限**（Tertiary） | `tertiaryProgressed(birth, age)` | **1 天 = 1 月**（用 30.4375 天/月；流派不一，已标注） |
| **太阳返照** | `solarReturn(birth, year)` | **二分法求回归瞬时**，60 次迭代 → 实测回归误差 **0.00003–0.00047°** |
| **月亮返照** | `lunarReturn(birth, afterDate)` | 同上，2 天窗口 |
| **太阳弧** | `solarArc(age)` | 年龄 × 0.985647° |
| **法达**（Firdaria） | `firdaria(birth, age)` | 昼/夜两套主期序列（10/8/13/9/11/12/7 年）+ 节点各 3 年（可选）；子期按主星起顺序各占 1/7 |
| **小限**（Profection） | `profection(ascSign, age)` | 年龄 N → 第 N 宫；**年主星 = 该宫星座的庙主星** |

**实测样例**（案例001，2007-12-25 17:30，昼生）：

| 年龄 | 法达 | 小限 | 次限 | 太阳返照 |
|---|---|---|---|---|
| 7 | 太阳 / 土星 | 8 宫 摩羯（土星） | 2008-01-01 | 2014-12-25 10:22 |
| 18 | 水星 / 水星 | 7 宫 射手（木星） | 2008-01-12 | 2025-12-25 02:23 |
| 25 | 水星 / 木星 | 2 宫 巨蟹（月亮） | 2008-01-19 | 2032-12-24 19:17 |

（法达校验：太阳 10 + 金星 8 = 18 → 18 岁落水星期 ✓；小限：7 岁 → 第 8 宫 ✓）

## 3 ★ 裁定 R-W13：占星**降级**为「心理八字」的补充

用户裁定：**占星机制降级，只作为心理八字的补充。**
与上一轮的实测完全一致 —— **占星侧在"婚恋应期"上处于噪声水平，掺入即降分**（R-E12）。

| 维度 | 占星侧的新定位 |
|---|---|
| **可以做的** | 描述**心理与主题演化**：法达的"人生主旋律"、小限的"年度主题"、次限/三限的"内在成长阶段"、返照盘的"年度情绪基调" |
| **不再做的** | ❌ 不再参与**事件发生**的预测与排序；❌ 不再与八字做等权融合；❌ 不碰健康（R-E13） |
| **代码含义** | 时序盘模块**不产出"某年必发生某事"**的断言，只给**可复算的数值描述**；`event-fit.mjs` 里占星特征默认权重保持 0（BaziQA/应期两处的实测结论） |
| **与八字的关系** | 八字给"结构与应期"，占星给"心理基调" —— **一主一辅，不并列、不平均** |

**心理八字（Psychological Bazi）** 的落地方式：八字侧出**性格/需求结构**（十神配比、身强弱、用忌），
占星侧用上述时序盘描述**该结构的心理演化节奏**。两者**不互相校准**，只在最终叙述里并列呈现。

## 4 占星融入大六壬：可行性评估（分三层，结论不同）

### 4.1 时间基座层 —— ✅ **已经融合，且是恒等式**

大六壬的**月将本身就是天文量**：月将 = **太阳过宫**（太阳所在黄道宫）。
本项目的知识库早已把它写成等式：

```
月将索引 = (10 − ⌊λ☉/30⌋) mod 12 = (1 − d☉) mod 12      // λ☉ = 太阳视黄经，d☉ = 太阳所在黄道宫序
```

**即：六壬的月将 = 占星的太阳星座序**，两者是同一个量的两种记法。
同理**天地盘的平移量 r = 占时 − 月将**，而占星的宫位框架旋转量就是**地方恒星时/时角** ——
**两套系统都在"按时间旋转一个十二分框架"，共享同一个数学核**。

### 4.2 符号层 —— ⚠️ **不能硬套，只能实证挖掘**

| 候选对应 | 可行性 | 理由 |
|---|---|---|
| 十二天将 ↔ 行星 | ❌ 无经典依据 | 天将是"贵人所临"的**方位序列**，不是行星；硬对应等于自造体系 |
| 四课三传 ↔ 相位 | ❌ 无依据 | 三传是"事态发展链"，与相位（角度关系）不同构 |
| 月将 ↔ 太阳 | ✅ **恒等** | 见 4.1 |
| 占时 ↔ 真太阳时 | ✅ **已实现** | R-T2 全局启用 |
| 干支 ↔ 黄经 | ✅ 已有 | L2 盘面层：地盘方位支 i ⟷ 黄经 270+30i |

### 4.3 结论

**可行的部分已经可行（时间基座与盘面旋转，且是数学恒等，不是"相似"）；
不可行的部分（天将↔行星、三传↔相位）缺经典依据，硬套就是编造。**

要让它**从"恒等"推进到"有信息"**，唯一正当路径是**实证挖掘**：
收集**带真实结果的六壬课例**，统计**课体/三传与行星配置的共现**（lift + 多重比较校正，同 R-V3 协议）。
→ **而本项目目前一条真实六壬课例都没有**（`data/divination/example-da-liu-ren.json` 只是格式示例）。
**所以这一层现在无法验证，也就不该下结论。** 这比给一个"看起来能融合"的答案诚实。

**R-W14**：六壬×占星融合**只承认数学恒等层**（月将↔太阳黄经、占时↔真太阳时、地盘↔黄经）；
符号层映射**必须经实证挖掘**，且需**带结果的课例** ≥30 条才谈得上验证。

## 6 已知未决

1. **韩式数据集尚未做职业预测**：职业字段是自由文本、多人多职业，需先**类目归一 + 分层对照**（控制了国别/年代/性别才谈得上结论）。
2. **命宫/身宫在此数据集永久不可算** —— 若要用，必须换**有时刻**的数据集（本库 `data/samples.jsonl` 的 21 条是完整对照）。
3. **占星时序盘尚未纳入任何实证**：本轮只完成"实现 + 口径 + 可复算验证"，**没有任何一条被证明有判别力**（这正是 R-W13 降级的直接后果：它不再被要求做预测）。
4. **六壬层缺数据**：一条真实课例都没有 → 4.2 的符号层无法验证。
5. 三限的"1 天 = 1 月"取 30.4375 天，与部分流派的 27.32 天（恒星月）不同 —— 已标注，待人工裁定。
