# 西方本命盘生成器 · 规则冻结表 v1.0

目标：把「出生时间 + 经纬度」变成 Part5/Part6 能直接消费的 `{ planets, aspects }`，**打通 `--at` 到星盘**，不再手填 JSON。
实现：`src/western/natal.mjs`；CLI：`cli-natal.mjs`（或 `cli-bazi.mjs --lat/--lon/--tz`）。

---

## 计算链（全部复用 astronomy-engine）

| 步骤 | 方法 | 说明 |
|---|---|---|
| 本地时间 → UTC | `toUTC(at, tz)` | 无时区标记时按 `tz`（默认 +8）解释；带 `Z`/`±hh:mm` 则不重复扣 |
| 十行星地心视黄经 | `Ecliptic(GeoVector(body, t, true)).elon` | **已是当日真黄道**（2020 春分实测 0.0000°），勿再叠岁差 |
| 格林尼治视恒星时 | `SiderealTime(t)` | 返回小时；`LST = GAST + lon/15` |
| 黄赤交角 | `e_tilt(t).tobl` | 真交角 |
| 上升 / 天顶 | 标准球面公式 | 见下 |
| 平交点 | Meeus 多项式 | 年退行 ≈ −19.34° |
| 逆行 | 与 12 小时后比较 | 太阳/月亮/交点不判逆 |

```
RAMC = LST·15 (度)
MC   = atan2( sin RAMC,  cos RAMC · cos ε )
Asc  = atan2( cos RAMC, −( sin RAMC · cos ε + tan φ · sin ε ) )
```

## 宫位制
| 制 | 定义 | 性质 |
|---|---|---|
| `porphyry`（默认） | 4 宫头=IC、7 宫头=Desc、10 宫头=MC；把 天顶→上升 与 上升→天底 两段黄道弧各分三等份 | 四分仪制，无迭代 |
| `equal` | 1 宫头=Asc，每 30° 递推 | 无迭代 |
| `whole` | 1 宫头 = 上升所在星座起点 | 无迭代 |
| ~~Placidus~~ | **未实现**（需迭代，高纬度会退化） | 见 §未决 |

## 相位
角度 → 名称：0 合相 / 60 六分相 / 90 四分相 / 120 三分相 / 150 梅花相 / 180 对冲。
参与天体：十行星 + 上升 + 北交点（按固定顺序，输出顺序稳定）。

## 实现裁定

| 编号 | 未定义处 | 裁定 |
|---|---|---|
| R-W1 | 用哪个宫位制 | 默认 **porphyry**；`--house-system equal\|whole` 可换。三者都保证对宫差 180°、每宫跨度 <180° |
| R-W2 | 交点用平/真 | 用**平交点**（确定性多项式）；与真交点最大差 ±1.5°，如需真交点另建 |
| R-W3 | 无时区标记如何解释 | 默认 **+8**；`--tz` 覆盖；带 `Z` 则视为 UTC 不重复扣 |
| R-W4 | 容许度与取整 | 默认 6°，日月之间 8°；**宫位用未取整宫头计算**，仅显示值取整（否则恰在宫头的星体会误判到前一宫） |
| R-W5 | 默认地点 | 未传 `--lat/--lon` 时用北京 39.9042N/116.4074E（仅作占位，正式排盘必须显式给地点） |
