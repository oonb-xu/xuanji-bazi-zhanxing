# 测试基准盘说明（FIXTURES）

## 出生时间已从公开仓库移除

`test/` 里的断言需要固定的四柱 / 昼夜 / 节气边界，因此依赖若干基准盘的**出生时刻**。

这些时刻**不再以明文出现在仓库中**，而是外置到一个本地私有文件：

```
test/fixtures.local.json     ← 已在 .gitignore 排除，不会上传
```

`test/_fixtures.mjs` 负责读取它：

```js
export const F = JSON.parse(fs.readFileSync('test/fixtures.local.json', 'utf8'));
// F.T1 … F.T7 对应第 1~7 个基准盘
```

**若该文件不存在，相关测试会打印「跳过本套测试」并 `exit 0`** ——
所以 clone 下来的公开仓库里，这部分测试是**跳过**而不是失败。

## 想在本机跑全量测试

自己准备 `test/fixtures.local.json`，填任意一组**虚构**时刻即可，例如：

```json
{
  "T1": "2000-01-01 12:00",
  "T2": "2000-01-02 12:00",
  "T3": "2000-01-03 12:00",
  "T4": "2000-01-04 12:00",
  "T5": "2000-01-05 12:00",
  "T6": "2000-01-06 12:00",
  "T7": "2000-01-07 12:00"
}
```

> ⚠ 注意：部分断言写死了特定四柱的结论，换成任意时刻可能**断言失败**。
> 想跑通全量，需要用能复现对应四柱的时刻；这部分数据由维护者本地持有。
