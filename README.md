## 关于 · 它算什么 · 你的数据去哪了

🔒 隐私承诺（请先读这条）

**本站只收集：匿名出生信息。**也就是——出生年月日时、出生地（城市/经纬度）、性别。这些是排盘必需的输入。

**本站绝不收集、不请求、不存储：**

- ❌ 任何 API Key / 令牌 / 密码
- ❌ 姓名、手机号、邮箱、微信、身份证
- ❌ 账号登录信息（本站**没有登录**）
- ❌ 浏览记录、设备指纹、第三方统计埋点

排盘计算**全部在你的浏览器与服务端本地完成**，不会转发给任何第三方。

        只有你在「反馈」页**主动点提交**时，才会把**匿名命例**存入数据库用于模型校准——同样不含姓名与任何联系方式。

你可以随时在浏览器里清空数据；我们没有账号体系，也就没有"注销"这件事——因为没有东西可注销。

这是什么

把三样东西放在一起看：**八字**（出生年月日时排出的四柱）、**星盘**（出生那一刻天上的行星位置）、**六壬**（按占问时刻起的课）。三种方法各有一套说法，这里不打架：**先找到它们底层的对应，融成同一张盘**，再用白话摊给你看。能对应上的地方就是融合；确实对不上的地方才并排列出、不硬凑。

一句话

你把出生时间地点填进去，它**先把三套体系翻译到同一个坐标上、融成一个模型**，再用白话摊给你看。它不替你下结论——下结论的是你。

三种办法分别是什么（用白话说）

- **八字**：把出生年月日时各换成两个字，一共八个字（所以叫"八字"）。每个字下面还藏着"藏气"，是一层更细的看法。
- **星盘**：算出你出生那一刻，太阳、月亮和其他几颗星各在天空的什么位置，画成一个圆盘。上面那些连线叫"相位"，表示两颗星之间的角度关系。
- **六壬**：这不是算人的，是**算事**的——你心里有件想问的事，把它起念的那个时刻填进去，它按老规矩推演三步给你看（这三步叫"三传"）。

★ 最容易出错的地方：出生时间

你填的是**手机/钟表上的时间**。但老办法要用的是**"当地太阳真正在头顶的时间"**——这两者在中国能差**一个多小时**（因为全国统一用北京时间，可太阳并不是按北京的时间升落的）。本站会自动帮你换，换完如果时柱变了会红字提醒。

还有两种情况，差**几分钟**结果就完全不同：

- **出生时间卡在两个时辰之间**（比如 16:58 前后）——差 5 分钟，最后两个字就换成别的。
- **出生时间卡在两个星座交界**——差 3 分钟，"上升星座"就换一个，所有跟上升有关的说法**全部作废**。

所以：**出生时间记不准的，请先去"矫正"页**。提供几件有确切年月的人生大事，它就能反推出更可能的时间。

哪些可以信，哪些别信

**可以信的：算得准不准。**八个字、藏气、行星度数、宫位、三传——都按固定规则算出来，换谁算都一样，错了也能复查。

**不能全信的：算得灵不灵。**

- 合盘那个分数衡量的是**"两张盘的结构像不像、补不补"**，不是"你俩能不能过一辈子"。它**没有用真实情侣的结局校准过**。
- 两个人怎么相处、愿不愿意让步、遇事怎么选——**这些东西盘里没有**。
- 八字讲"木火土金水"，星盘讲"火土风水"，**字面是两套完全不同的说法**——能对应的部分本系统已经对齐融合了，只有对不上的地方才并排列出，不硬凑成一个数。

最后

它是一台**把老规矩拆开给你看**的机器，不是算命先生。它给的每个数字你都可以不信——但至少你能看见它是**怎么算出来的**。

## 怎么用 · 需要接 API 吗

排盘本身不需要 API。八字、星盘、融合盘、四钟时序、动态十神权重、神煞——
          全部在这台机器上用本地引擎算，**不联网、不上传**。

          只有「AI 解读」这一层需要 API（把算出来的结构交给大模型组织成一段人话）。
          不接 API，前面的计算和图表全部照常可用，只是没有那段文字解读。


          另外两类场景也建议接入 API：

          · **生时矫正**：本地算法只能给出**候选时间集**（用事件反推，命中区间可能不止一个）；
          要让模型综合多个事件做全局约束求解、收敛到唯一解，需要 API。

          · **模型精确度**：本地是确定性规则引擎，精度是"给定输入必得同一结果"的精确；
          但**断语的取舍与组合**（哪条更重要、冲突怎么权衡）本地只能给并列，不会替你排序——
          这一步建议交给模型。

          本机实测参考：月支可从行星位置 100% 推出；
          时支经均时差修正后约 67.5%（边界附近可能差一位）⇒ **高标准场景请接入 API 复核**。

想要精确度，建议必须接 API —— 无论你是什么用途。

        本站内置算法足以把结构算完（八个字、行星度数、宫位、三传），这部分**不接 API 也是准的**。

        但下面三项**依赖外部星历与更细的历法数据**，内置版只能给近似：

        · **高精度行星位置**（内置与专业星历可能差角分级）

        · **历史时区与夏令时**（尤其 1949 年前、境外出生）

        · **边界情形**（出生时刻卡在时辰交界 / 星座交界）

        所以：**只要你在意"准不准"，就接 API**——与用途无关，看盘、合盘、矫正、研究都一样。

## 这不是拼贴，是底层逻辑对应

本系统不是把两套体系的输出结果拉在一起做对照。

          它做的是：先找到两个体系在底层真正对应的那个量，再在那个量上建立映射。

**两者的区别是根本性的：**

          ✗ 结果拼贴：占星说「土星入庙」⇒ 好；八字说「官杀重」⇒ 压力大。
          两句并列摆着，靠人去找感觉。这种对照**没有可检验的基础**，换一个人能给出相反的解读。

          ✓ 底层对应：先证明「月支」与「太阳黄经」是**同一个事实的两种命名**
          （节气就是太阳黄经的 30° 刻度，立春 315° = 建寅）—— 这是恒等式，不是比喻。
          映射建立在恒等式上，才能被机器检验、被别人复现。

本系统已经找到的底层对应（可机检）：

| 底层对应 | 为什么是"同一个量" | 实测 |
|---|---|---|
| 月支 ⇔ 太阳黄经 | 节气就是太阳黄经的 30° 刻度，两者是同一事实的两种命名 | 100% |
| 时支 ⇔ 太阳时角 | 时辰是时角的 2 小时分块；均时差由太阳黄经反算 | 67.5% |
| 七政 ⇔ 七曜 | 同源体系（均出自巴比伦黄道十二宫），名异实同 | 严格 |
| 罗睺/计都/月孛 ⇔ 北南交点/月亮远地点 | 同一轨道要素的两个名字 | 严格 |
| 十二宫 ⇔ 生活领域 | 占星与紫微的宫位功能一一对齐 | 结构 |

以及明确承认做不到的：

          · **年柱、日柱无法从行星位置推出 —— 60 甲子里的「60」**确有天文近似依据**：它是 LCM(12木, 30土)，也 ≈ 3 次木土会合（59.577 年）；且 6 个甲子日 = 360 天，与回归年 365.2422 天咬合 98.56%。但「60」在这套体系里**是计数，不是可测的几何量** —— 星盘能给出所有角度，却给不出"这是第几个甲子"。要从落位反推年柱/日柱，必须有一个**外部纪元锚点**（如 1984 = 甲子）。这是原理性边界，不是精度问题。

          · 两套体系的心理/物质庙旺不在同一根轴上**（占星 f(星,星座)=心理；紫微 f(星,宫位)=物质），
          所以它们给出相反结论时**不是矛盾**，而是各测各的层面——**正因为不在同一根轴上，才拼得进同一张盘**。

          **凡是不能对应的，本系统不允许它去对应。**

更完整的论证见 [《论中西命理体系的融合路径》](https://oonb-xu.github.io/xuanji-minglironghe/paper.html)。

## 方法论 · 融合路径论文

融合路径的重新论述 · 以七政四余为骨架做「逆向复现」

以前我们讲的是「四套体系怎么对应」。现在改成更根本的问法：
            **为什么不从七政四余出发，反推另外三套各自丢掉了哪一环？**

七政四余的特殊地位：四套里只有它保持「真实天体位置 → 宫次宿度 → 人事」的
            **全程可追溯**，每一个判断都能回溯到一个可测的天文量（黄经 / 宿度 / 时角）。
            **它是唯一"每一环都还有物理对应物"的体系**，所以拿它当骨架。

| 体系 | 保留的天文量 | 在哪一步切断、换成了什么 |
|---|---|---|
| 七政四余 | 七政 + 四余的宿度与黄经（全量） | **全链保留** ⇒ 骨架 |
| 古典占星 | 黄经 → 星座 / 宫位 | 人事侧换成**心理轴**，宫位变成「领域标签」 |
| 八字 | 太阳黄经（月支）、时角（时支） | **年柱、日柱换成纯计数**，与天体脱钩 |
| 紫微斗数 | **无**（只用农历月日时） | 全链**符号化**，只留「地支↔星↔宫」排布规则 |

这不是高下，是**不同的编码选择**：八字用计数换**可机算**，紫微用符号化换**强结构**，占星用心理轴换**细腻**。
            代价都是同一个 —— **某一环的物理可追溯性被切断**。

逆向复现四步：

1. **坐标还原**：每个量标注它锚定在哪个物理量上 —— 黄经 / 时角 / **计数** / **查表**。
2. **截断点识别**：找出"换了对象"的地方 —— 几何→计数（年柱日柱）、几何→查表（藏干十神神煞）。
3. **按链重装**：以七政四余的链为骨架，每套体系**只在自己保留最完整的那一段说话**。
4. **精进补正**：古人修过的（超辰 / 岁差 / 定朔 / 真太阳时 / 均时差）我们补；**古人没修的（60 甲子天文对位）明确标为设计选择，不补也不假装补**。

装配结果（三层，全站共用）：

| 层 | 内容 | 能否由星盘反推 |
|---|---|---|
| ① 几何层 | 黄经 → 月支（**100%**）；时角 → 时支（**67.5%**）；ASC → 命宫/身宫 | 可反推 |
| ② 计数层 | 年柱、日柱（含日主） | 不可反推 |
| ③ 符号层 | 藏干、十神、神煞、紫微宫名 | 查表即得 |

所以「能不能用行星宫位反推八字」这个问题，本身应该拆成三问 ——
            **几何层能、计数层不能、符号层不用推**。这才是"逆向复现"该给出的答案。

还有一条纪律：七政四余用**宿度**（恒星黄道，岁差约 50.29″/年），八字用**节气**（回归黄道，锁太阳）。
            二者混用会出系统性偏差，所以我们**分开记账** —— 月支锚回归黄道，宿度层单独标岁差，不混算。

这套系统为什么这样设计、边界在哪里，都写在
          [**《论中西命理体系的融合路径》**](https://oonb-xu.github.io/xuanji-minglironghe/paper.html) 里。

          核心结论：**七政四余与古典占星同源**（均出自巴比伦黄道十二宫）；
          两套体系的底层差异不在文化而在**编码类型**——
          占星是纯几何编码（位置自足），八字是几何+计数混合编码（含人为甲子原点）。

          这条差异可以严格证明：**月支 100% 可直接从太阳黄经推出；年柱日柱也能推，但路径不同**
          （年柱日柱不是"从几何直接得出"，而是要走两步：**逆星历**把星位还原成绝对日期 → 再按**历法锚点**换算干支。中间那一步不携带天文信息，但只要锚点给定，结果就是确定的）。

## 各体系独有优势 别的体系结构上做不到的事

换了问法之后，「各体系独有优势」这个问题应该重新提：
            **与其问"它有什么优点"，不如问"在整条链的哪一段，它是唯一还站得住的"**。
            因为每套体系都只在自己**保留最完整**的那一段最强 —— 别的段落它并不比别人强。

| 体系 | 最强的一段 | 具体能力 |
|---|---|---|
| 七政四余 | **天文层** 宿度 → 宫次 | 星曜的**实际位置**与庙旺、四余（罗睺/计都/月孛/紫气）—— 唯一能对上**恒星宿度**的体系 |
| 古典占星 | **几何层 → 心理侧** | 星座 + 宫位**双维度**刻画、相位几何、本质尊贵 —— 「黄经 → 星座/宫位」这一段它最完整 |
| 八字 | **计数层 → 力量侧** | **十神的相对性**（同一个字，换个日主就换意义）、身强弱与扶抑、大运流年的**时序** —— 计数层是它独有的 |
| 紫微斗数 | **符号层 → 结构侧** | 十二宫**强结构**、四化（禄权科忌）、星曜组合与亮度 —— 全链符号化换来的结构密度最高 |

逐条展开（只看它在那一段为什么不可替代）

七政四余 · 天文层

· **宿度为锚**：唯一直接落在二十八宿上的体系，岁差可单独记账

· **四余独有**：罗睺/计都（交点）、月孛（远地点）、紫气 —— 占星没有对应物

古典占星 · 几何层（心理侧）

· **双维度**：同一颗星在不同星座 / 不同宫位，意义不同，且两轴独立

· **相位几何**：角距是纯几何量，不依赖历法，故最稳定

八字 · 计数层（力量侧）

· **相对性**：十神是"关系"而不是"东西"，这是别的体系结构上给不出的

· **可机算**：计数层不依赖天文，纯查表 + 算术即可复现 ⇒ 可批量验证

· **时序强**：大运/流年给了明确的时间刻度

紫微斗数 · 符号层（结构侧）

· **宫位结构化**：十二宫各司其职，领域划分最细

· **四化**：禄权科忌给了一种"同星不同作用"的机制

· **代价**：天文输入为零，所以它能说"哪里"，说不了"多强"

⇒ **融合的准确表述**：不是"四套都拿来用"，而是
            **让每套体系只在自己保留最完整的那一段说话，其余段落让它闭嘴**。
            这也就是上一节「逆向复现」第四步（按链重装）在功能层的落地。

## 实验性假说 · 如果真实周期是 59.58 年

这是一个假说，不是结论。它问的是：
          如果八字的真实周期不是整数 60，而是 **3 次木土会合 = 59.577 年**，
          那么哪些柱会变、哪些不会、什么时候会开始不一致？

① 问题的由来：节气一直在修，干支是冻结的

          中国历史上改历极为频繁（汉太初历、三统历、大衍历、授时历、时宪历……），
          **每一次的核心目的都是修节气**——因为节气必须跟着真实太阳位置走。

          但**干支纪年/纪日是一套冻结的 60 进位**，它不随历法一起修正。
          如果真实天文周期不是正好 60，那么这套冻结的刻度就会**越走越偏**。

② 偏差有多大（本站实算）

| 量 | 数值 | 说明 |
|---|---|---|
| 标准周期 | 60.0000 年 | 60 甲子 |
| 木土会合 | 19.8590 年 | synodic |
| 3× 会合 | 59.5770 年 | 假说中的"真周期" |
| 每周期差 | 0.4230 年 = 155 天 | 这就是"微分" |
| 每年相对推进差 | 0.710% | 逐年累积 |

③ 影响面：只动 3 处，不动 5 处

| 柱 / 项 | 由什么决定 | 是否受 59.58 影响 |
|---|---|---|
| 年柱 | 60 甲子年循环 | **★ 受影响** |
| 月干 | f(年干, 月支) | **★ 连带受影响**（年干变则月干变） |
| 胎元 | 月干+1、月支+3 | **★ 连带受影响** |
| 月支 | 节气（太阳黄经 30° 刻度） | 不变 —— 节气本就随天文修正 |
| 日柱 | 连续天数 mod 60 | 不变 —— 与木土周期无关 |
| 时柱 | 日干 + 时支 | 不变 |
| 命宫 / 身宫 | f(月支, 时支) | 不变 |

⇒ **七柱里只有三处会被这个假说改动**。这意味着即便假说成立，影响面也远小于"整盘作废"。

④ 什么时候才真的会不一致（实算 1800–2200）

          本站以 **1984 = 甲子** 为共同锚点，逐年比较标准年柱与 59.577 版年柱：

· 1984–2124 之间（约 150 年）：两者完全一致 —— 对现代出生的人，
            这个假说**不改变任何结果**。

          · 1800–1983 与 2125 以后：开始分歧，最大差 2 步。

          · 全区间分歧年占比 **64.8%** —— 但这是因为扫描窗口大部分落在 1984 的两侧之外。

⑤ 用法的修正（这一条最容易做错）

          不能"直接用日历年重算年柱"——因为**立春之前的日期，其八字年属于上一年**。
          正确做法是：**只取「同年数下标准索引与实验索引之差」，把这个差分施加到盘上真实的年柱上**。
          本站已按这个方式实现并自检（年柱不变 ⇒ 月干必然也不变）。

⑥ 何时会提示你使用实验性排盘

          排盘页在以下情况会**显式提示**，而不是悄悄换算法：

          · 出生年份落在 **1984±150 年之外**（此时两套年柱可能不同）

          · 盘上实际年柱与实验年柱**不一致**

          · 届时给出**两套结果并排**（标准版 vs 你选择的实验版），**绝不替你选**。

**这一步的意义**：把"历法冻结 vs 天文漂移"这个隐性问题，变成**可开关、可对比、可复现**的实验。
          无论假说最终成立与否，**能把它量化到"只动三处、只影响 ±150 年之外"，本身就是一条结论**。

          复现：`node tools/verify-experimental-calendar.mjs`

A. 先订正一句话：我说过「现代排盘不受影响」——这话有前提

那个结论**只在「按历法计数、以近世锚点重同步」的前提下成立**（例如以 1984 = 甲子锚定）。
          因为 **60 甲子是一台计数器**（`ℤ/60ℤ`），只要锚点确定，它永远准确——
          它**不需要**和天文对上。

但如果要求**「从历元起天文连续」**，结论就反过来了。以汉太初历元（前 104 年）为锚外推：
          
· 至今天数 **2,129 年**
          
· 累计偏移 **15.01 年** ⇒ **年柱要错 15 位**
          
· 若以 1984 = 甲子锚定，至今 41 年只偏 **105.6 天**（约 3.5 个月）

| 锚点选择 | 至今累计偏移 | 影响 |
|---|---|---|
| 1984 = 甲子（通行做法） | 105.6 天（≈3.5 个月） | 年柱不变；只在立春附近 ±3.5 个月有争议 |
| 汉太初历元 前 104 年 | 15.01 年 | 年柱错 **15 位**，月干随之整列变化 |
| 不设锚点、纯天文外推 | 随时间线性增长 | 每 142 年错 1 年，**无法自洽** |

⇒ 所以「从万年历最开始推」这件事，**恰恰是天文上无法验证的那一步**：它是一次**计数约定的选择**，
          不是可测的量。订正后的准确说法是：**在计数约定下现代排盘无漂移；在「天文连续」假设下现代排盘早已错位。**

B. 本质是微分问题：误差是一阶线性项，不是周期项

设日历周期 `T_c = 60`（整数定义在 ℤ 上），天文周期

`T_a = 3 / (1/11.862 − 1/29.457) = 59.576971…` 年

两者相位函数与相位差：

`Φ_c(t) = t/T_c mod 1`，`Φ_a(t) = t/T_a mod 1`

          `ΔΦ(t) = t·(1/T_a − 1/T_c) = t·k`，**k = 1.183425×10⁻⁴ /年**

**关键结论**：`ΔΦ(t)` 是 **t 的一次函数**——这叫**久期项（secular term）**，不是周期项。
          它的一阶导数是常数：

`dε/dt = k·T_a = 7.050×10⁻³`（无量纲，恒定）

          ⇒ **二阶项为 0**；误差**单调累积、永不回头**

**推论（这才是本质）**：既然 `dε/dt ≡ 常数`，那么**任何"周期性修补"都不可能消除它**——
          只能用**离散重锚（reset）**把它归零。这正是古代历法「超辰」在干的事（见 D 节）。
          八字缺的，就是这一步 reset。

| 需要累计到的偏移 | 所需时间 | 换算 |
|---|---|---|
| 1 个月 | **11.8 年** | ≈ 0.2 个甲子周期 |
| 半年 | 70.9 年 | ≈ 1.2 个甲子周期 |
| 1 年（年柱错 1 位） | **141.8 年** | ≈ 2.4 个甲子周期 |
| 10 年 | 1,418 年 | ≈ 24 个周期 |
| 整个 60 年周期 | 8,510 年 | ≈ 142 个周期 |

相对速率：`k·T_a = 0.705%/周期`（每 60 年漂 **0.423029 年 = 154.51 天**）。

C. 还有个更快的漂移：「6 个甲子日 = 360 天」

360 天 vs 回归年 365.2422 天 ⇒ **每年亏 5.2422 天**，咬合率 **98.56%**。
          看着只差 1.44%，但它是**另一个一阶线性项**，而且比年柱那个快得多：

| 累计 | 所需时间 |
|---|---|
| 亏满 1 个月（30.4 天） | **5.8 年** |
| 亏满 1 个甲子日周期（60 天） | **11.4 年** |

⇒ 「6 甲子日 ≈ 一年」只能当**近似**。若真把它当历法用，**11 年就整周期错位**。
          这也是为什么日柱必须靠**连续日计数 + 历法锚点**，而不能靠天文推出（与「年柱日柱不可由行位推出」是同一件事）。

D. 古人早就发现并修过：岁星「超辰」 —— 而八字没有这一步

古籍原文：「**岁星右行于天，一岁移一辰，十二岁一小周，千七百二十八年一大周**」
          （[《识典古籍·岁》](https://www.shidianguji.com/character/%E5%B2%81)）。

注意 **1728 = 12 × 144**：这就是「**144 年超一辰**」的结构——
          岁星纪年名义上 12 年走一辰（12 次），但真实周期短一点，跑满一段时间就会**多走一辰**，
          于是历法必须**跳过一辰**来复位。这个动作叫 **超辰（超次）**。

| 口径 | 隐含岁星周期 | 超一辰间隔 |
|---|---|---|
| 三统历古法 | 12 / (1 + 1/144) = **11.9172 年** | **144 年** |
| 现代真值 | 11.862 年 | **86 年** |

这和 59.58 是**同一种病**：**整数周期 ≠ 实际周期**，误差是一阶线性的，只能靠离散重锚修。
          古人在**岁星纪年**上做了这件事（超辰），在 **甲子纪年**上没做——
          因为甲子从一开始就被当作**纯计数**，不承担天文对位。**这是设计选择，不是疏漏。**

E. 冷暖与物候：月建的名义季节，比实际物候早整整一个月建

八字讲「冷暖」，靠的是**月建**；月建严格绑定**太阳黄经**（节气）。但气温对太阳有**热惯性滞后**：

| 极值 | 天文时刻（节气） | 实际最值 | 滞后 |
|---|---|---|---|
| 最冷 | 冬至 12-21（子月始） | 大寒 01-20（丑月中） | **30 天** |
| 最热 | 夏至 06-21（午月始） | 大暑 07-22（未月中） | **31 天** |
| 一个中气间隔 | 365.2422 / 12 = 30.44 天 | 基准 |

⇒ **热滞后 = 31 / 30.44 = 1.02 个月建**。**整整一个月建**。
          也就是说：**以月建论冷暖，名义上永远比实际物候早一个月**。逐月对照：

| 月建 | 节气起 | 名义 | 实际物候 |
|---|---|---|---|
| 寅 | 立春 02-04 | 春季始 | 仍在严寒，回暖初期 |
| 卯 | 惊蛰 03-06 | 仲春 | 真正回暖 |
| 辰 | 清明 04-05 | 季春 | 暖而湿 |
| 巳 | 立夏 05-06 | 夏季始 | 实际仍偏春 |
| 午 | 芒种 06-06 | 仲夏 | 初夏 |
| 未 | 小暑 07-07 | 季夏 | **热极在此** |
| 申 | 立秋 08-08 | 秋季始 | 实际仍热 |
| 酉 | 白露 09-08 | 仲秋 | 转凉 |
| 戌 | 寒露 10-08 | 季秋 | 干凉 |
| 亥 | 立冬 11-07 | 冬季始 | 凉而不寒 |
| 子 | 大雪 12-07 | 仲冬 | 寒但未极 |
| 丑 | 小寒 01-06 | 季冬 | **冷极在此** |

**历史叠加**：小冰期（约 1300–1850，其中蒙德极小期 1645–1715 最冷）让春季再推迟 1–2 周，
          物候与月建的错位在那些年份更大。**所以「某人八字喜火但生在小冰期」这类判断，
          按节气算的冷暖会系统性地偏「暖」。**

F. 什么时候会真的引发误差 —— 精确到月

| 情形 | 误差性质 | 触发时间（精确） |
|---|---|---|
| ① 把 60 年当**天文周期**用 | 一阶线性，单调 | **11.8 年**累计到 1 个月；**141.8 年**错 1 整年（年柱错 1 位）；**8,510 年**整周期 |
| ② 以**月建论冷暖** | 系统偏差（非随机） | **每一个盘都错 1.02 个月建**——冷极在丑、热极在未，而名义上分别记在子、午 |
| ③ 把「6 甲子日 = 360 天」当历法 | 一阶线性，更快 | **5.8 年**错 1 个月；**11.4 年**错 1 个整周期（60 天） |
| ④ 岁星纪年不超辰 | 一阶线性 | 古法口径 **144 年**必须跳一辰；现代真值下 **86 年**就该跳 |
| ⑤ 小冰期出生者 | 气候偏移（有界） | LIA 约 1300–1850 年区间内，物候再偏 **1–2 周**；蒙德极小期 1645–1715 最强 |

**一句话总括**：①②③④ 都是**同一个数学对象**——「整数周期 vs 实数周期」的**一阶线性误差**
          （`dε/dt = const ≠ 0`）。它能被**离散重锚**归零，不能被测度修正消除。
          古代历法用「超辰」做了重锚；八字把 60 甲子当纯计数，**主动放弃了天文对位**，
          于是既没错、也没修——**这正是它可机算的前提，也是它不能反过来证伪天文的原因**。

大周期精确模型 · 用真实星历量出来，而不是线性外推

上一节说的是**一阶线性项**（久期漂移）。但真实天体轨道误差是**长周期**的——
          只要周期够长，**几百年窗口内完全可以精确建模**，不必外推到几千年。
          本节用 `astronomy-engine` 扫出 **1702–2298 年（596 年）全部 31 次木土会合**，实测其周期结构。

| 量 | 实测值 | 说明 |
|---|---|---|
| 单次会合间隔 | 平均 **19.8653** 年，σ = 0.5052，极差 **1.3776**（19.13–20.51） | 理论 19.85899；**单次抖得厉害** |
| 3 次会合跨度 （对应「60 年」） | 平均 **59.58991** 年，极差仅 **0.119 年（43 天）** | 理论 59.576971；**三次一组几乎是常数** |
| 与 60 的差 | **−0.454 ~ −0.366 年**（−166 ~ −134 天） | 稳定在 −5 个月左右 |
| 会合点黄经推进 | 单次 **−116.66°**；三元组净 **+10°** | 每 60 年沿黄道挪约 10° |
| 绕行一周 | ≈ 36 个三元组 ≈ **2145 年** | 会合点转满 360° 的大周期 |
| 间隔自相关 | 峰值在滞后 **3 个会合**，**r = 0.992** | 强周期结构，周期 ≈ 60 年 |

这就是「大周期精确运算」的结构：
          误差不是单调漂移，而是
          **「≈60 年为节拍的振荡」**（r = 0.992）叠加
          **「≈2145 年的慢绕行」**。
          所以在**几百年窗口**内，可以用实测的周期表精确修正——不需要线性外推到几千年。

**但要诚实说明两件事**：

          ① 单次会合间隔抖动达 ±0.7 年，**拿单次会合当"60 年刻度"是不可靠的**；必须**三次一组**才稳定。
          
② 上述 59.5899 比理论 59.5770 略大 0.013 年，差异来自**行星摄动与所选窗口**——
          换窗口数值会微变，说明**它是窗口统计量，不是宇宙常数**。

复现：`node tools/bigcycle-v2.mjs`（输出 reports/jupiter-saturn-bigcycle.json）

## 体系冲突 · 话说不到一起去的地方

这一节专门写"对不上"的地方。不藏、不平均、不用一句话圆过去。
          每条都标明**性质**：是精度不足（可修）、
          流派差异（并列呈现，不合并成一个数）、还是原理性不可通约（不修，直接禁止对应）。

| 冲突 / 不一致 | 性质 | 具体表现 | 本站的处理 |
|---|---|---|---|
| 心理 vs 物质判定相反 | 不同轴 不是冲突 | 月亮天蝎：占星「落」；太阴在亥：紫微「庙」 | 两轴各算各的、并列输出「物质有靠，但心里不安」 |
| 命宫 / 身宫口径分歧 | 流派差异 | 本地引擎：命宫戊寅 / 身宫丙戌；iztro：命宫乙酉 / 身宫酉（14/26法 vs 和法） | 两套并排显示，**不取其一**；未判定谁对 |
| 月将 vs 月建 | 约定不同 | 月建按**节气**换、月将按**中气**换，中点差半个月 | 明确写明**不存在固定偏移**，禁止按 ±n 宫硬算 |
| 父母宫位置 | 体系差异 | 紫微父母宫在十二宫第 12 位；占星父母常看 4 / 10 宫 | **并列呈现，不折算** |
| 七政庙旺 vs 占星本质尊贵 | 同一轴 若相反才是真冲突 | 两者都是 f(星, 星座)，可直接比较 | 本条**才是真冲突**：并列不平均，标 `sameAxis` |
| 时支只能推到 67.5% | 精度不足 | 偏差集中在时辰边界（±1 位），缺均时差以外的残余误差 | 标 `measuredAccuracy: 0.675`，**不可替代真实出生时辰** |
| 年柱 / 日柱不可从落位推出 | 原理性 | 年柱/日柱是**计数**；但可由**逆星历**还原日期后按历法锚点换算 | 须**历法锚点**；**能推**，但不靠几何直推 |
| 60 甲子连续性只是假设 | 史料问题 | 独立检验：前113→1965 跨 2077 年精确对上；汉太初历元差 1 位 | 承认**局部 1 天级调整**；对公元前日柱不作断言 |
| 二十八宿 | 不可通约 | 赤道分度，与黄道十二宫是非线性关系；长短悬殊（井 31° vs 觜 2°） | 只做**位置标注**，不折算成星座或宫位 |
| 紫炁 | 不可通约 | 纯中国概念，西方占星无对应物 | 标为**不可通约**，**不强行换算** |
| 神煞 ↔ 心理 | 内部一致性 | 只能算"收敛度"，不能证明该心理倾向必然显现 | 标为**内部一致性**，**不是外部验证** |

三条不可让步的处理原则：

          **①** 能把性质说清的，一定标明（精度 / 流派 / 不可通约）——让人知道该不该信这一条；

          **②** 同一轴上的相反结论**并列不平均**；不同轴上的相反结论**各自成立**，并给出完整读法句；

          **③** 不可通约的，**禁止它去对应**——宁可少说，不做虚假统一。

如果你认为上面某一条有解 —— 这个项目是开源的，请直接在这个模型上跑。

            以上每一条"做不到"，我们都附了**可复现的脚本与数据格式**。
            你可以：

            · 用你自己的数据重跑（tools/ 下每个结论都对应一个可执行脚本）

            · 直接改算法（核心模块在 src/cross/ 与 src/bazi/，全部有独立断言）

            · 提出反例（能跑出不同结果的样本最有价值）


            我们不认为这些边界是终点。它们是**当前版本在哪停下**的诚实记录——
            而记录本身就是为了被后来者推翻。

更完整的论证与边界讨论见 [《论中西命理体系的融合路径》](https://oonb-xu.github.io/xuanji-minglironghe/paper.html) 第八节。

## 实验性板块 · 60 甲子到底连不连续

本节是实验，不是结论。它检验一个流传的质疑：
          「60 甲子循环在历史上从未连续，现代排盘的日柱是错的」。

          我们不复述该说法，而是**用精确儒略日独立重算**，看它在算术上站不站得住。

① 方法（学自该质疑方，值得学的部分）

· 只用**史料原创干支**做锚（《史记·封禅书》、Wechsler 1985 唐礼制、《元史》），不靠现代反推

          · 算两锚之间**精确天数差**，`mod 60`，与记载干支对账

          · 其最有价值的一点：从现代往前反推古历是循环论证 ——
          反推必然"强迫"古日拟合 60 循环，因此永远对得上，不能用它证明连续性

          · 其方法的一处弱点（本站修正）：用「年数 × 365.2422」算天数会引入近似误差；
          跨闰日必须直接算**儒略日（JDN）之差**，它按定义就是整数天。本站已用 JDN 重算，
          并用 2000-01-01 = JDN 2451545、1582-10-15 = JDN 2299161 自检通过。

② 本站实测结果

| 锚点对 | 精确天数差 | mod 60 | 预测 | 史料 | 判定 |
|---|---|---|---|---|---|
| 前113-12-24（辛巳） → 1965-01-10 | 758,263 天 | 43 | 甲子 | 甲子 | ✅ 对上 |
| 前113-12-24（辛巳） → 前105-12-24 | 2,922 天 | 42 | 癸亥 | 甲子 | ❌ 差 1 位 |
| 前105-12-24（记甲子） → 1965-01-10 | 755,341 天 | 1 | 乙丑 | 甲子 | ❌ 差 1 位 |

⇒ 结论一（支持该质疑方的具体指控）：
          前 113 → 1965 这条两千年长链**精确自洽**；而**汉太初历元（前105-12-24）恰好差 1 位**。
          这与「汉武帝把该是癸亥的一天定为甲子」的指控**在算术上吻合**。

⇒ 结论二（不支持其大结论）：
          但其总标题「60 循环从不连续、现代日柱错 ≥3 位」**不成立**——
          因为跨越 2077 年的 前113→1965 链条是**对得上**的。可见是**局部 1 天级的人为调整**，
          而非长期断裂。

⇒ 结论三（本引擎的处境）：
          本引擎的日柱是**从现代纪元连续反推**得到——这正是被批评的方法。
          实测：1965-01-10 引擎给甲子 ✅（与史料一致）；但公元前年份 tyme4ts 不支持，
          引擎给出的是无意义值。**因此本站对公元前的日柱不作任何断言。**

**对主流学术的对照**：Adam Smith (2010) 指出 60 循环的连续性**只是"被假设"**；
          中文学界唯一的怀疑仅见李学勤 (1957) p.122；并称"没发现任何重置的文本痕迹，此疑问很少被提出"。
          ⇒ **连续性确实是假设而非证明**，这一点本站接受；但"已被证明断裂"同样缺乏证据。

          **本节的定位**：把"假设"变成"可检验的命题"，并给出可复现的算术结果。
          相关质疑方为 Prof. Dr. Ong Hean-Tatt（马来西亚 GUI Management Centre，非北京大学），
          我们借其方法、修正其算术、核对其结论，**不采信其关于"八字系伪造自紫微斗数"的附带主张**。

复现：`node tools/experiment-jiazi-continuity.mjs`

## 这种融合体系该怎么发展 · 先对账，再融合

这一节不谈技术，谈**为什么这件事一直没做成**，以及**如果要做成，顺序应该是什么**。

一、七政四余为什么会落寞失传

| 原因 | 具体机制 |
|---|---|
| 门槛过高 | 要用到真实星历、宿度、岁差、四余（交点/远地点），每一步都要算；而子平术只需查表加减 |
| 历学垄断 | 历代钦天监把历法与星占列为禁学，民间私习天文有罪（唐至明皆有禁令） |
| 术语壁垒 | 庙旺、喜忌、四余层层堆叠，外行**无法验证**，只能信或不信 |
| 断语靠师承 | 结论无法机检，传承一断就彻底失传 |
| 竞争劣势 | 子平术用**最少输入**给出**最直接的话**，传播成本极低 |
| 西学东渐 | 清以后西方占星以"新式"面貌进入，七政四余夹在中西之间，**两边都不认它** |

⇒ **它不是"因为不准"而消失，而是"成本太高、无法验证、无法普及"而消失。**
          这一点很重要：**失传不等于失效**，也可能只是输给了传播效率。

二、为什么融合总是艰难

| 层面 | 冲突来源 |
|---|---|
| 输入 | 一个要求精确到分钟 + 经纬度，一个只要年月日时 |
| 编码 | 几何编码 vs 计数编码（年柱、日柱）—— 两套不同性质的对象被当成同类 |
| 权威 | 各有祖师、各有经典，方法论互不承认 |
| 可检验性 | 断语模糊，**无法判定谁对**，于是只能比资历 |

**根本原因**：大家一直在**符号层**对话（十神 vs 宫位 vs 星曜），
          从来没有回到**几何层**做核对。符号层没有共同尺子，所以永远谈不拢。

三、两个体系的人，对彼此的偏见

| 偏见 | 表现 | 事实 |
|---|---|---|
| 中式看西学 | "占星只会说性格，算不了事" | 古典占星本有**事件预测**传统，只是现代心理占星把它弱化了 |
| 西学看中式 | "八字是宿命论，不自由" | 十神是**关系**不是宿命；但它确实缺少"自由意志"这一层语言 |
| 双方共同 | "对方是伪科学" | 双方都缺少**可复现的验证机制** —— 这是共同短板，不是一方的问题 |

**有意思的是**：这两套体系**同源于巴比伦黄道十二宫**（见第二节）。
          吵得最凶的两家，其实是一个祖先 —— 偏见来自**中断的记忆**，不是来自本质差异。

四、融合艰难的底层原因：没有从最底层的天文数据做精确核算

这是本文最核心的一个判断，也是这个项目**真正的起点**：

- 四套体系都在**符号层**互相翻译，**没人回到几何层对账**；
- 八字的月支本来**严格绑定太阳黄经**（恒等），但没人去核算过；
- 七政四余的宿度会随**岁差**漂移（约 50.29″/年），但没人标出来；
- 60 甲子被当成"天意"，没人算过它和木土会合之间那 **0.423 年**的差。

所以这个项目做的第一件事**不是"融合"，而是"对账"**：

| 对账项 | 实测结果 |
|---|---|
| 月支 ↔ 太阳黄经 | 恒等 100%（节气就是黄经 30° 刻度） |
| 时支 ↔ 太阳时角 | 67.5%（需均时差 + 真太阳时，边界附近差一位） |
| 60 甲子 ↔ 木土会合 | **3 次会合 = 59.58991 年**，极差仅 0.119 年（43 天） |
| 命宫 ↔ 上升点 ASC | 结构对应（命宫 = f(月支, 时支) ≈ ASC 的粗糙算法） |
| 年柱/日柱 ↔ 逆星历 | **可推但需转一道**：星位 → 绝对日期 → 历法锚点 → 干支 |

⇒ **对完账之后，"融合"才不是比附，而是"在同一把尺子上量出来的结果"。**

五、所以应该怎么发展：四步顺序不能颠倒

| 步骤 | 做法 |
|---|---|
| ① 先对账 | 把每个量的物理锚点标清楚：**能算的算，不能算的明确标"计数"**，绝不假装差一点 |
| ② 再分层 | 几何层 / 计数层 / 符号层，各层不越界 —— 不让符号层的结论去冒充几何层的证据 |
| ③ 后验证 | 用**事件样本**（出生时间 + 事例）做统计检验，而不是靠祖师权威或个案神验 |
| ④ 最后才解释 | 有了统计支撑，再谈"为什么" —— 否则解释只是事后编故事 |

**一句话**：这个体系要发展，不是靠"更玄"，而是靠
          **更可算、更可验、更可复现**。
          七政四余当年输在"成本"上，那就把成本降到能算；八字赢在"可机算"上，那就把它的物理锚点补回去。

说明：本节是**立场与判断**，不是已完成的证明。文中「对账」各项的实测数据可在
          [59.58 假说](#sec-59-58) 与
          [实验性板块](#sec-experiment) 中复核。
