npm install

核心结论（已实测）

对账项结果
月支 ↔ 太阳黄经恒等 100%
时支 ↔ 太阳时角67.5%（需均时差 + 真太阳时）
60 甲子 ↔ 木土会合3 次会合 59.58991 年（极差 0.119 年）
命宫 ↔ 上升点 ASC结构对应
年柱/日柱 ↔ 逆星历可推，但须经「逆星历 → 日期 → 历法锚点」

三层结构

层内容能否反推
① 几何层黄经→月支、时角→时支、ASC→命宫可
② 计数层年柱、日柱可，但要转一道
③ 符号层藏干、十神、神煞、紫微宫名查表即得
